## 这个专题是什么

[HF Daily Papers](https://huggingface.co/papers) 每天会从当天新上传的 arXiv 论文里挑一批（通常 20–60 篇）挂出来，靠 upvotes 排序。它是**目前最省时间的「AI 进展信号源」**：不需要自己扫 arXiv 列表，但要读得动 30 篇摘要也不现实。

所以这个专题的做法是：**每天一篇，一天不落**。抓当天全部论文 → 按主题分组 → 每篇给 3–5 条（问题 / 方法 / 数字 / 为什么值得看）→ 开头 Top 10 表 → 结尾三个观察。目标不是「读完全部」，而是**十分钟内知道昨天该关注什么、哪些可以跳过**。

## 写作口径（为什么值得每天看一份固定格式的日报）

固定格式换来的可比性，比单篇写得漂亮更重要：

- **组内按 upvotes 降序**：热度是噪声很大的信号，但「同一天内的相对热度」有信息量。
- **数字必须落地**：`25×`、`70.2% vs 62.6%`、`+12.8 个百分点`——不写「显著提升」。
- **点明关键取舍**：每篇至少一句「它放弃了什么」（例如决策模型放弃自由生成、潜空间通信放弃可解释的文本接口）。
- **标出工程意义**：与训练系统 / kernel / 优化器 / agent 工程相关的，直接说能落到哪个问题上；不相关的（医学、金融实证）归到「当日其它」一节的末尾，不占版面。

## 三条防坑规则

1. **只写摘要里出现过的数字**，不猜、不外推；摘要没给规模的，明说「摘要没给」。
2. **区分 arXiv 首发日与 daily 收录日**：`submittedOnDailyAt` 才是当天榜单的日期，两者常差 1–3 天。
3. **重复论文降级处理**：同一个 arXiv id 在近期日报里出现过，就只加一句「已在 X 日提过」，不再展开。

## 怎么复现

抓取脚本在 [`code/ai-daily/`](https://github.com/BlueSkyyyyyy/tech_record/tree/main/code/ai-daily)：

```bash
python3 code/ai-daily/fetch_papers.py --date 2026-11-06
```

标准库实现，走 HF 官方 API；直连不通时自动退到镜像或解析页面内嵌 JSON。抓完输出 JSON + 一份人读 brief，日报正文基于 brief 重写（不直接贴 brief）。
