# 位运算：异或消消乐、数 1 与递推

位运算题的特点是「代码极短、思路很巧」。它不靠复杂的数据结构，而是直接利用二进制表示
本身的性质，把一个个整数的每一位当成可以拆开、合并、抵消的独立信息。很多人遇到位运算
题会条件反射地「一位一位去模拟」，其实真正好用的往往只有那么几个固定套路：**异或用来
配对抵消**、**`n & (n - 1)` 用来清掉最低位的 1**、**把大问题拆成「低位 + 高位」的递推**。

本篇先立起三块最基础的积木。136 用异或的「自反性」把成对的数消掉，留下落单的那个；
191 用 `n & (n - 1)` 每次清掉一个 1，数出二进制里 1 的个数；338 则把「数 1」这件事
从「逐个算」升级成「从更小的数递推」，一次求出 0 到 n 所有数的答案。三题合起来覆盖了
位运算最常用的三种动作：**抵消、清位、递推**。

有了这三块积木，后面七题都是它们的组合与变形：268、461 继续用异或做「补齐」和「标出
不同位」；231 把清位动作用在「判是否只有一个 1」上；190、201 则是「逐位搬移」和
「保留公共前缀」两种直接操作位串的写法；371 让异或与进位配合完成加法；78 用二进制位
当一张「选 / 不选」的开关表来枚举集合。

| 模式 | 题目 | 难度 |
|---|---|---|
| 模式一：异或消消乐（配对抵消） | 136. 只出现一次的数字 | 简单 |
| 模式二：清掉最低位的 1 | 191. 位 1 的个数 | 简单 |
| 模式三：位运算递推（不重复计算） | 338. 比特位计数 | 简单 |
| 模式四：异或补齐找缺失 | 268. 丢失的数字 | 简单 |
| 模式五：异或标出不同位 | 461. 汉明距离 | 简单 |
| 模式六：判「只有一个 1」 | 231. 2 的幂 | 简单 |
| 模式七：逐位搬移构造新数 | 190. 颠倒二进制位 | 简单 |
| 模式八：保留公共前缀 | 201. 数字范围按位与 | 中等 |
| 模式九：二进制位当开关表 | 78. 子集（位枚举） | 中等 |
| 模式十：异或与进位做加法 | 371. 两整数之和 | 中等 |

读这三题时请特别留意「**一次运算同时处理所有二进制位**」这个视角：异或是在所有位上并行
地做「相同为 0、不同为 1」，`n & (n - 1)` 是在一条等式里精确地抹掉最低位的 1，而 338 的
递推则是把「低位」的信息直接搬到「高位」上。理解了它们背后的二进制含义，后面遇到位掩码、
状态压缩、只出现 k 次一类的问题，都能顺着同一套思路推下去。

## 模式一：异或消消乐（配对抵消）

**适用信号**：一堆元素里，除了极少数「落单」的，其余都成对出现，要在 O(1) 额外空间里
找出落单者（或找出唯一的异常值）。

**核心动作**：把全部元素依次异或进一个累加器。异或满足交换律、结合律，且 `a ^ a = 0`、
`a ^ 0 = a`，所以成对的元素无论顺序如何都会两两抵消，最后只剩下没被抵消的那个。

### 136. 只出现一次的数字（简单）

**题目**：给定非空整数数组 `nums`，除某个元素只出现一次外，其余每个元素都出现两次。
找出只出现一次的元素，要求线性时间、常数额外空间。

**思路**：

维护一个初值为 `0` 的累加器 `result`，遍历数组，每读到一个数就把它异或进去：
`result ^= x`。遍历结束后，`result` 就是答案。

**为什么异或能自动配对抵消**：异或的规则是「同一位上两个数相同则为 0、不同则为 1」。
同一个数异或自己，每一位都相同，结果全是 0，也就是 `a ^ a = 0`。而异或又满足交换律和
结合律，可以把数组中所有出现两次的数两两凑到一起，它们全部变成 0；0 异或任何数还是
那个数，于是唯一没被凑对的那个数就保留了下来。整个过程不需要知道哪个数和哪个数配对，
顺序也无关紧要。

**为什么不用哈希表**：哈希表（计数）能解决问题，但要额外 O(n) 空间来存「每个数出现了
几次」。异或把所有信息压缩进一个整数，恰好只保留「出现次数的奇偶性」，而题目保证只有
一个数出现奇数次，所以 O(1) 空间就够。凡是「其余都成对、找落单」的题，都该先想到异或。

**代码**（完整可运行版见 `src/bit/single_number.py` / `.cpp`）：

```python
def single_number(nums):
    result = 0
    for x in nums:
        result ^= x
    return result
```

```cpp
int singleNumber(const std::vector<int> &nums) {
    int result = 0;
    for (int x : nums) {
        result ^= x;
    }
    return result;
}
```

- **复杂度**：时间 O(n)（每个元素异或一次），空间 O(1)。
- **易错点**：初值必须是 `0`（`0` 是异或的单位元，`0 ^ x = x`）；不能先排序再数，
  那样虽然也能做但会破坏 O(n) 的要求；`result` 的初始值若误写成第一个元素再遍历
  全部元素，就会把第一个元素多异或一次。
- **相似题**：268. 丢失的数字（`0..n` 与数组元素异或，落单者即缺失值）；
  191. 位 1 的个数（见下，同样是对二进制逐位处理）；
  287. 寻找重复数（可用快慢指针做，但「值当指针」的思想和位运算一样都是把整数当数据
  结构）；此题若改成「其余元素出现 3 次」，异或就失效了，需改为「逐位统计 1 的个数再
  对 3 取模」。

## 模式二：清掉最低位的 1

**适用信号**：需要数出一个数二进制里 1 的个数、判断它是不是 2 的幂、或者只关心「最低位
的那个 1」在哪里。

**核心动作**：`n & (n - 1)` 会精确地把 `n` 中最低位的那个 1 变成 0，其余位不变。反复
执行直到 `n` 归零，就能数出 1 的个数；而「执行一次就归零」则说明 `n` 只有一个 1。

### 191. 位 1 的个数（简单）

**题目**：给定一个整数 `n`（视作无符号 32 位二进制），返回其二进制表示中「1」的个数
（汉明重量）。

**思路**：

循环执行 `n = n & (n - 1)`，每执行一次就清掉一个 1，同时把计数器加一；直到 `n` 变成 0，
计数器的值即为答案。

**为什么 `n & (n - 1)` 恰好清掉最低位的 1**：设 `n` 最低位的 1 在第 `k` 位，那么从第
`k` 位往下看，`n` 的形状是 `...1 0 0 ... 0`（第 `k` 位是 1，更低的位全是 0）。减去 1 时，
第 `k` 位向更低处借位，变成 0，而所有更低的位全部翻转成 1，得到 `...0 1 1 ... 1`。两者
按位与：第 `k` 位是 `1 & 0 = 0`，更低的位是 `0 & 1 = 0`，更高的位完全一样所以原样保留。
于是第 `k` 位及其以下全部归零，正好抹掉了一个 1，且位置是最低的那个。

**为什么比「逐位右移统计」更省**：逐位检查要对固定 32 位各做一次「取最低位 + 右移」，
循环次数固定是 32；本方法只在 1 的个数次循环后就退出。对二进制里 1 很少的数，速度快了
不少，而且循环次数本身就等于答案，语义更直接。

**代码**（`src/bit/number_of_1_bits.py` / `.cpp`）：

```python
def hamming_weight(n):
    count = 0
    while n:
        n &= n - 1
        count += 1
    return count
```

```cpp
int hammingWeight(std::uint32_t n) {
    int count = 0;
    while (n) {
        n &= n - 1;
        ++count;
    }
    return count;
}
```

- **复杂度**：时间 O(k)（`k` 是 1 的个数，最坏 O(32)），空间 O(1)。
- **易错点**：`n & (n - 1)` 写成了 `n & (n - 1)` 就没问题，但若误写成 `n & (n >> 1)`
  那是另一个动作（保留相邻两位都为 1 的位置），意思完全不同；Python 的整数是任意精度
  的，负数按无穷位补码解释，若输入可能为负，应先 `n &= 0xFFFFFFFF` 截成 32 位无符号；
  C++ 里参数用 `std::uint32_t` 或 `unsigned int`，避免有符号右移带来的歧义。
- **相似题**：338. 比特位计数（用本动作做递推，见模式三）；231. 2 的幂（`n > 0 且
  n & (n - 1) == 0` 即只有一个 1）；342. 4 的幂（在 2 的幂基础上再要求那个 1 落在偶数
  位）；461. 汉明距离（`(a ^ b)` 的 1 的个数，异或把不同的位标成 1，再用本题统计）。

## 模式三：位运算递推（不重复计算）

**适用信号**：要一次性求出 `0..n` 每个数的某个按二进制定义的量（如 1 的个数、奇偶性、
最低位等），且相邻两数的二进制表示高度相关。

**核心动作**：找出「大数」与「去掉某些低位后的小数」之间的递推关系，让后者的答案已经
算好、直接复用，从而把每个数的求解降到 O(1)。

### 338. 比特位计数（简单）

**题目**：给定整数 `n`，返回长度 `n + 1` 的数组 `ans`，其中 `ans[i]` 是 `i` 的二进制
表示中 1 的个数（`i` 从 0 到 `n`）。

**思路**：

设 `ans[i]` 为 `i` 的 1 的个数。把 `i` 右移一位相当于扔掉它最低位，于是有递推式：

```
ans[i] = ans[i >> 1] + (i & 1)
```

`i & 1` 正是指被扔掉的最低位是不是 1。例如 `i = 6`（二进制 `110`），`i >> 1 = 3`
（`11`）已经有 2 个 1，最低位 `6 & 1 = 0`，故 `ans[6] = 2`，与手数一致。从 `i = 1`
到 `n` 正序填表即可。

**为什么这样比逐个统计快**：对每个 `i` 单独数 1 是 O(log i)，总共 O(n log n)。而 `i >> 1`
一定小于 `i`（`i > 0` 时），也就是说递推用到的是**已经算好的更小下标**，每次只做「一次
右移 + 一次取与 + 一次加法」，把 O(log i) 的非线性统计降成了 O(1) 的查表。这正是动态
规划「用已知的小状态推大状态」的思想，只不过状态之间靠移位连接。

**另一种等价写法**：`ans[i] = ans[i & (i - 1)] + 1`。因为 `i & (i - 1)` 会清掉 `i` 最低
位的那个 1（见模式二），得到比 `i` 少一个 1 的数，所以它已经算好的答案加 1 就是 `ans[i]`。
两种递推都对，`i >> 1` 版本从「高一阶」推，`i & (i - 1)` 版本从「少一个 1」推，可任选。

**代码**（`src/bit/counting_bits.py` / `.cpp`）：

```python
def count_bits(n):
    ans = [0] * (n + 1)
    for i in range(1, n + 1):
        ans[i] = ans[i >> 1] + (i & 1)
    return ans
```

```cpp
std::vector<int> countBits(int n) {
    std::vector<int> ans(n + 1, 0);
    for (int i = 1; i <= n; ++i) {
        ans[i] = ans[i >> 1] + (i & 1);
    }
    return ans;
}
```

- **复杂度**：时间 O(n)（每个 `i` 只做常数次位运算），空间 O(n)（返回数组本身）。
- **易错点**：递推依赖「更小下标已经算好」，所以必须从 `1` 往 `n` **正序**遍历；`ans[0]`
  恒为 0（0 没有 1），初始化时不要漏；`i & 1` 括号不能省，否则运算优先级会出错；
  若改用 `ans[i & (i - 1)] + 1`，注意 `i = 0` 也要停在初值 0。
- **相似题**：191. 位 1 的个数（本递推的「单点版本」，见模式二）；338 的 `i & (i - 1)`
  写法直接复用了它的清位技巧；这类「从更小数递推」也可迁移到「数二进制里 0 的个数」、
  「判断奇偶」等按位定义的量上。

## 模式四：异或补齐找缺失

**适用信号**：一个本该「连续、完整」的序列里少了一个数（或多了 / 重复了一个数），要
在不排序、不用额外空间的前提下找出来。

**核心动作**：把「实际给出的元素」与「本该出现的完整集合」全部异或起来。两边都有的
元素自动两两抵消，最后剩下的就是只出现在一侧的异常值。

### 268. 丢失的数字（简单）

**题目**：给定一个包含 `0..n` 中 `n` 个不重复整数的数组 `nums`，找出缺失的那个数。

**思路**：

把数字 `0..n` 与数组里的每个数都异或进同一个累加器。为了省掉额外遍历，可以让
`result` 初值为 `n`（数组长度，正好补上 `0..n` 里最大的那个 `n`），然后对每个下标 `i`
把 `i` 和 `nums[i]` 一起异或进去：

```
result = n
for i, x in enumerate(nums):
    result ^= i ^ x
```

**为什么异或能自动指出缺了谁**：完整集合 `0..n` 和数组只差一个数。异或满足交换律、
结合律，把两边的元素按「值相等」配对，每一对 `v ^ v = 0` 都消掉；于是所有两边都出现的
数全清零，只剩那个「只在完整集合里出现、数组里没有」的数，它异或上 0 还是自己，答案
就浮现了。注意这跟模式一（找出现一次的数）是同一个动作，只是「配对的两堆」换成了
「下标集合」和「数值集合」。

**为什么不直接求和**：求和（`0..n` 的和减数组和）也对，但累加可能溢出；异或逐位运算
不需要考虑进位，天然不会溢出。

**代码**（`src/bit/missing_number.py` / `.cpp`）：

```python
def missing_number(nums):
    result = len(nums)
    for i, x in enumerate(nums):
        result ^= i ^ x
    return result
```

```cpp
int missingNumber(const std::vector<int> &nums) {
    int result = static_cast<int>(nums.size());
    for (std::size_t i = 0; i < nums.size(); ++i) {
        result ^= static_cast<int>(i) ^ nums[i];
    }
    return result;
}
```

- **复杂度**：时间 O(n)，空间 O(1)。
- **易错点**：`result` 的初值要设成 `n`，否则会漏掉最大数 `n` 这一项；循环里要把
  「下标 `i`」和「数值 `nums[i]`」都异或进去，少异或一个就配不成对；如果题目允许
  重复数字或多缺几个，异或就不够用了，得改用计数或排序。
- **相似题**：136. 只出现一次的数字（同一种互补配对，见模式一；本题可看作「下标与值
  互为参照」的版本）；41. 缺失的第一个正数（用「值当指针」原地置换，思想同源但更硬）；
  448. 找到所有数组中消失的数字（用下标取负做标记，等价于「用值本身标记它该在的位置」）。

## 模式五：异或标出不同位

**适用信号**：要比较两个整数的二进制到底有哪些位不一样、有几个位不一样。

**核心动作**：`a ^ b` 的每一位规则是「相同为 0、不同为 1」，所以它把「不同的位」精确地
标成 1；再对结果数 1 的个数（模式二）就得到不同位的数量。

### 461. 汉明距离（简单）

**题目**：两个整数 `x`、`y` 之间的汉明距离，指它们二进制表示中不同位的个数。求距离。

**思路**：

先算 `z = x ^ y`。`z` 中为 1 的位，正是 `x`、`y` 在该位上取值不同的位置；为 0 的位
则说明两者相同。于是汉明距离就等于 `z` 中 1 的个数，直接用模式二的
`while z: z &= z - 1; count += 1` 统计即可。

**为什么用异或而不是逐位比较**：逐位比较要对 32 位各做一次「取位 + 判断」，而一次异或
就把「哪些位不同」这个信息并行地算了出来，剩下的只是数 1。这正是位运算「一次操作处理
所有位」的体现。

**代码**（`src/bit/hamming_distance.py` / `.cpp`）：

```python
def hamming_weight(n):
    count = 0
    while n:
        n &= n - 1
        count += 1
    return count


def hamming_distance(x, y):
    return hamming_weight(x ^ y)
```

```cpp
int hammingWeight(std::uint32_t n) {
    int count = 0;
    while (n) {
        n &= n - 1;
        ++count;
    }
    return count;
}

int hammingDistance(int x, int y) {
    return hammingWeight(static_cast<std::uint32_t>(x ^ y));
}
```

- **复杂度**：时间 O(k)（`k` 是不同位的个数，最坏 O(32)），空间 O(1)。
- **易错点**：异或的两个操作数在 C++ 里要先转成无符号再数 1，避免有符号右移 / 补码
  带来的歧义；`x ^ y` 别写成 `x | y`（或运算会把「都为 1」的位也算进去，不能表示
  「不同」）；Python 的 `int` 位数不受限，本题正整数范围内无需额外掩码。
- **相似题**：191. 位 1 的个数（本题的统计部分，见模式二）；477. 汉明距离总和（把
  「两两异或数 1」按每一位分别统计：某位有 `c` 个 1、`n - c` 个 0，贡献 `c * (n - c)`，
  避免两两枚举）；136. 只出现一次的数字（同样以异或为核心，见模式一）。

## 模式六：判「只有一个 1」

**适用信号**：判断一个数是不是 2 的幂、4 的幂，或者一般的「二进制里是否恰好一个 1」。

**核心动作**：`n & (n - 1)` 能清掉最低位的 1（模式二）。如果清一次就变成 0，说明 `n`
本来只有一个 1；但要注意 `n = 0`、负数也要另行排除。

### 231. 2 的幂（简单）

**题目**：给定整数 `n`，判断它是否是 2 的幂。

**思路**：

2 的幂的二进制恰好只有一个 1（`1`、`10`、`100`、`1000`…）。于是只需两个条件：

```
n > 0 且 n & (n - 1) == 0
```

`n > 0` 排除了 0（0 与 `n - 1 = -1` 按位与也是 0，会误判）和所有负数；`n & (n - 1) == 0`
则保证至多只有一个 1。两者合起来正好刻画「恰好一个 1」。

**为什么不用循环不断除以 2**：除法版本要做 O(log n) 次取模和除法，而位运算只需一次
与操作，O(1) 完成，且不依赖语言对浮点 / 整除的细节。

**代码**（`src/bit/power_of_two.py` / `.cpp`）：

```python
def is_power_of_two(n):
    return n > 0 and (n & (n - 1)) == 0
```

```cpp
bool isPowerOfTwo(int n) {
    return n > 0 && (n & (n - 1)) == 0;
}
```

- **复杂度**：时间 O(1)，空间 O(1)。
- **易错点**：`n > 0` 千万不能漏，否则 0（甚至某些负数）会被误判为 2 的幂；运算符
  优先级上 `n - 1` 要先算，写成 `n & n - 1` 会先做与再减，结果全错，务必加括号写成
  `n & (n - 1)`；C++ 里 `n` 若为 `INT_MIN`，`n - 1` 会溢出，不过 `n > 0` 已经先挡掉了。
- **相似题**：342. 4 的幂（在 2 的幂基础上，再要求那个唯一的 1 落在偶数位，可用
  `0x55555555` 掩码检查）；326. 3 的幂（3 的幂不能用二进制位判断，改用「能否被最大的
  3 的幂整除」）；191. 位 1 的个数（`n & (n - 1)` 的原始出处，见模式二）。

## 模式七：逐位搬移构造新数

**适用信号**：要把一个整数的二进制位整体反转、循环移位，或按位重新排列。

**核心动作**：每次从原数取出最低位，放到新数的对应位置，然后把两边各移动一位。核心
是一个固定次数的循环，第 `i` 轮负责把「原数第 `i` 位」搬到「新数第 `31 - i` 位」。

### 190. 颠倒二进制位（简单）

**题目**：给定一个 32 位无符号整数 `n`，返回把它二进制位上下颠倒后的结果。

**思路**：

维护结果 `ans`，循环 32 次，每次：
- `ans = (ans << 1) | (n & 1)`：先把 `ans` 左移腾出最低位，再把 `n` 当前最低位放进去；
- `n >>= 1`：丢掉刚处理过的这一位，下轮处理更高一位。

32 轮之后，原来的最高位被搬到了最低位，最低位被搬到了最高位，整体颠倒完成。

**Python 的掩码为什么必要**：Python 整数是任意精度、负数按无穷位补码解释，若不截断，
`ans << 1` 会一直往高位长出，`n >>= 1` 对负数也永远不会归零。所以先 `n &= 0xFFFFFFFF`
把它固定成 32 位无符号，每次左移后再 `& 0xFFFFFFFF`，保证结果只在 32 位内。

**代码**（`src/bit/reverse_bits.py` / `.cpp`）：

```python
def reverse_bits(n):
    n &= 0xFFFFFFFF
    ans = 0
    for _ in range(32):
        ans = ((ans << 1) | (n & 1)) & 0xFFFFFFFF
        n >>= 1
    return ans
```

```cpp
std::uint32_t reverseBits(std::uint32_t n) {
    std::uint32_t ans = 0;
    for (int i = 0; i < 32; ++i) {
        ans = (ans << 1) | (n & 1u);
        n >>= 1;
    }
    return ans;
}
```

- **复杂度**：时间 O(32) == O(1)（固定轮数），空间 O(1)。
- **易错点**：循环次数必须是 32（题目约定 32 位），不能写成「while n」按有效位数循环，
  否则高位补零的顺序会错；Python 必须加掩码，C++ 用无符号类型避免算术右移引入符号位；
  `ans << 1` 与 `| (n & 1)` 的顺序不能反，反了会把新位覆盖掉。
- **相似题**：191. 位 1 的个数（同样「每轮取最低位」的循环骨架，见模式二）；
  7. 整数反转（十进制版的「逐位搬移」，逻辑完全一致只是进制不同）；190 的进阶写法
  「分治法两两交换」可把 32 次循环降到 5 步，但可读性差，面试写直观版即可。

## 模式八：保留公共前缀

**适用信号**：要对一段连续整数区间整体做按位与 / 按位或，问最终哪几位还能保留下来。

**核心动作**：区间内相邻数不断加 1，低位会不停翻转；只要某一位在区间里既出现过 0 又
出现过 1，按位与后一定是 0。能活下来的只有「所有数都相同」的那段高位，也就是区间两端
的公共前缀。

### 201. 数字范围按位与（中等）

**题目**：给定 `left`、`right`（`left <= right`），返回 `[left, right]` 内所有整数按位
与的结果。

**思路**：

不断把 `left` 与 `right` 一起右移，直到两者相等——相等说明已经把「不同的低位」全部
移掉，剩下的是公共前缀。记下右移次数 `shift`，最后把 `left` 左移 `shift` 位补回低位
的 0：

```
shift = 0
while left < right:
    left >>= 1
    right >>= 1
    shift += 1
return left << shift
```

例：`left = 5 (101)`、`right = 7 (111)`。右移一次得 `2 (10)`、`3 (11)`，仍不等；再右移
得 `1`、`1`，相等，`shift = 2`，答案为 `1 << 2 = 4 (100)`，与 `5 & 6 & 7 = 4` 一致。

**为什么「不同的低位」必然被清零**：设某一位在 `[left, right]` 内既有取 0 的数又有取 1
的数。由于区间是连续的，每加 1 都会让最低的若干位翻转，位从 0 变 1 再变 0 的过程中，
至少存在一个数该位为 0。按位与只要遇到一个 0 就钉死为 0，所以这些位最终全部消失，只剩
公共前缀。右移对齐正是在找这个前缀。

**代码**（`src/bit/range_bitwise_and.py` / `.cpp`）：

```python
def range_bitwise_and(left, right):
    shift = 0
    while left < right:
        left >>= 1
        right >>= 1
        shift += 1
    return left << shift
```

```cpp
int rangeBitwiseAnd(int left, int right) {
    int shift = 0;
    while (left < right) {
        left >>= 1;
        right >>= 1;
        ++shift;
    }
    return left << shift;
}
```

- **复杂度**：时间 O(32) == O(1)（最多右移 32 次），空间 O(1)。
- **易错点**：循环条件写成 `left < right`（相等就停），若写成 `left != 0` 之类会多移；
  返回值别忘 `<< shift`，否则只剩下前缀而低位没补零；`left == right` 时代入循环直接
  跳过、`shift = 0`，恰好返回 `left` 本身，是正确特例。
- **相似题**：191. 位 1 的个数（按位与 / 右移的基本功，见模式二）；201 与
  「按位或」版本 898 子数组按位或操作对比：或运算下位只会从 0 变 1，处理方向正好相反；
  这类「公共前缀」思路也用于 Trie 里求最大异或对。

## 模式九：二进制位当开关表

**适用信号**：元素个数不多（`n` 通常 ≤ 20 左右），要枚举所有「选 / 不选」的组合；或
要把一个集合压缩进一个整数来判重、做状态压缩 DP。

**核心动作**：用一个整数的第 `i` 个二进制位表示「第 `i` 个元素选没选」。枚举从 `0` 到
`2^n - 1` 的所有整数，就等价于枚举所有子集；检查 `mask & (1 << i)` 就能知道第 `i` 个
元素在不在当前集合里。

### 78. 子集（中等）

**题目**：给定不含重复元素的整数数组 `nums`，返回它的所有子集（幂集）。

**思路**：

长度为 `n` 的数组，每个元素两种状态，共 `2^n` 种组合。让 `mask` 从 `0` 遍历到
`2^n - 1`：`mask` 的第 `i` 位为 1 表示选 `nums[i]`。对每个 `mask`，扫描所有位组装出
对应子集即可。

**和回溯篇 78 题的关系**：这是同一答案的两种视角。回溯在决策树上「逐个元素做决定」，
天然带剪枝，适合 `n` 较大；位枚举直接列出所有决定的结果，代码更短，但只能处理 `n`
不大（`2^n` 可枚举）的情况。二者互为补充，都属于「状态压缩」的起点——用一个整数表示
一个集合，是后面状压 DP、TSP 的基础。

**代码**（`src/bit/subsets_bitmask.py` / `.cpp`）：

```python
def subsets(nums):
    n = len(nums)
    res = []
    for mask in range(1 << n):
        subset = []
        for i in range(n):
            if mask & (1 << i):
                subset.append(nums[i])
        res.append(subset)
    return res
```

```cpp
std::vector<std::vector<int>> subsets(const std::vector<int> &nums) {
    int n = static_cast<int>(nums.size());
    std::vector<std::vector<int>> res;
    for (int mask = 0; mask < (1 << n); ++mask) {
        std::vector<int> subset;
        for (int i = 0; i < n; ++i) {
            if (mask & (1 << i)) {
                subset.push_back(nums[i]);
            }
        }
        res.push_back(subset);
    }
    return res;
}
```

- **复杂度**：时间 O(n · 2^n)（`2^n` 种组合，每种花 O(n) 组装），空间 O(n · 2^n)
  （结果本身占的空间，不计结果则额外 O(n)）。
- **易错点**：`1 << n` 在 `n` 较大时会溢出（C++ 的 `int` 到 `n = 31` 就越界），题目
  一般保证 `n ≤ 20`；`mask & (1 << i)` 的括号别丢；结果中子集的顺序由枚举顺序决定，
  如果要按字典序或长度排序需自行整理。
- **相似题**：78 题的回溯解（`docs/11-backtracking.md`，同一问题的决策树视角）；
  784. 字母大小写全排列（每一位二选一，可用位枚举或回溯）；416. 分割等和子集
  （`docs/13-dynamic-programming.md` 的 0/1 背包可用状压枚举小规模数据做暴力对拍）。

## 模式十：异或与进位做加法

**适用信号**：要求不用 `+`、`-` 等算术运算符实现加法；或想理解「加法器」在电路 / 位
层面到底怎么工作。

**核心动作**：把加法拆成「无进位和」与「进位」两部分：异或给出无进位的和，与运算指出
哪些位产生了进位，把进位左移一位后再当加数继续加，直到没有进位。

### 371. 两整数之和（中等）

**题目**：不用 `+` 和 `-`，计算两个整数 `a`、`b` 之和。

**思路**：

观察二进制加法：只看相加但不进位时，`1 + 1 = 0`、`1 + 0 = 1`、`0 + 0 = 0`，这正好是
异或的规则，所以 `a ^ b` 是「无进位和」。而只有两个都为 1 的位才会产生进位，`a & b`
恰好标出这些位置；进位要加到高一位，所以左移一位。把进位再当作新的加数加进去，重复到
进位为 0：

```
while b:
    carry = (a & b) << 1
    a = a ^ b      # 无进位和
    b = carry      # 进位作为下一轮加数
return a
```

**Python 为什么要掩码**：Python 整数任意精度、负数按无穷位补码解释，直接循环时
`carry` 会不断向高位延伸，`b` 永远到不了 0。因此每步都与 `0xFFFFFFFF` 截断成 32 位，
循环结束后再把结果从 32 位无符号还原成有符号（最高位为 1 时用 `~(a ^ mask)` 变回负数）。

**代码**（`src/bit/sum_of_two_integers.py` / `.cpp`）：

```python
def get_sum(a, b):
    mask = 0xFFFFFFFF
    while b:
        carry = ((a & b) << 1) & mask
        a = (a ^ b) & mask
        b = carry
    return a if a <= 0x7FFFFFFF else ~(a ^ mask)
```

```cpp
int getSum(int a, int b) {
    while (b != 0) {
        unsigned carry = static_cast<unsigned>(a & b) << 1;
        a = a ^ b;
        b = static_cast<int>(carry);
    }
    return a;
}
```

- **复杂度**：时间 O(32) == O(1)（每轮至少消掉一组进位），空间 O(1)。
- **易错点**：Python 不做掩码会死循环（进位无限增长）；还原符号时阈值是
  `0x7FFFFFFF`，超过它说明结果是负数；C++ 里 `a & b` 可能是有符号负数，左移是未定义
  行为，要先转 `unsigned`；循环结束条件是进位 `b == 0`，别把 `a` 当成条件。
- **相似题**：29. 两数相除（同样禁止乘除，用位运算 + 减法做「快速幂式」减法）；
  1. 两数之和（哈希版，判题名相同但完全是另一回事，注意区分）；371 的进位思路也用于
  371 类「不用算术运算符」的题目，如 面试题 08.05 递归乘法。

## 规律总结

1. **异或的三大性质是「配对」类问题的通用钥匙**：`a ^ a = 0`（自反）、`a ^ 0 = a`
   （单位元）、交换律与结合律（顺序无关）。只要题目出现「成对 / 落单 / 只出现奇数次」，
   先把所有元素异或起来，往往答案就浮出来了。

2. **`n & (n - 1)` 与 `n & (-n)` 是「操作最低位 1」的一对工具**：`n & (n - 1)`
   清掉最低位的 1（用来数 1、判 2 的幂）；`n & (-n)` 取出最低位的 1（用来找最低位、
   树状数组）。见到「关注最低位的 1」的信号，就从这两个式子里挑。

3. **位运算是「在所有位上并行」的**：一次异或同时处理 32 位，一次 `&` 同时判断多位，
   所以经常能把线性时间再压下一层常数。写位运算题要习惯用「每一位独立」的视角去读
   表达式，而不是把它当成一个普通的整数运算。

4. **逐位定义的量，先找相邻数的递推**：338 告诉我们，凡是「对每个数按二进制定义的量」，
   都可以试着用 `i` 与 `i >> 1`（或 `i & (i - 1)`）的联系从已算好的小状态 O(1) 推出，
   把 O(n log n) 降到 O(n)。这是位运算与动态规划的交汇点。

5. **数 1 的个数，先问「1 多还是 1 少」**：1 很少时用 `n & (n - 1)` 循环（次数等于 1 的
   个数）；1 很多、且需要反复查时用 338 的递推预打表。方法本身都不难，难在根据数据分布
   选对那一个。

6. **负数与溢出要单独交代**：Python 整数是任意精度、负数按无穷位补码语义，做位运算前常
   要先与掩码（如 `0xFFFFFFFF`）截断；C++ 要留意有符号右移是算术移位、以及左移溢出是
   未定义行为。题目说「无符号」时，就老老实实用无符号类型。

7. **异或不只是「消消乐」，还能「补齐」和「标差异」**：268 把缺失问题变成「完整集合与
   残缺集合异或」，461 把「找不同位」变成「异或后数 1」。同一个异或，换个说法就是一类
   新题——见到「缺失 / 重复 / 差异位」，先想能不能异或出那个异常。

8. **「操作位串」有两条常用路线：逐位搬移，和保留公共前缀**：190 属于前者，用一个固定
   次数循环把每一位搬到新位置；201 属于后者，用「两端一起右移直到相等」找到区间不变量。
   前者关心每一位的去向，后者关心哪些位在所有数里始终一致，读题时先分清是哪一种。

9. **一个整数就是一张集合的开关表**：把第 `i` 位当「第 `i` 个元素选没选」，`mask & (1<<i)`
   判断、`mask |= (1<<i)` 加入、`mask ^= (1<<i)` 取反，枚举 `0..2^n-1` 就是枚举所有子集。
   这是状态压缩的起点，78 的位枚举版本与回溯版本是同一答案的两种视角。

10. **二进制加法的本质是「异或 + 进位」**：无进位和是异或，进位是 `a & b` 左移一位，
    把进位当加数迭代到零就完成加法（371）。理解这一层，既能在禁用算术运算符时写出答案，
    也能解释电路里的半加器 / 全加器。

11. **难度不在技巧而在「位视角」的切换**：本篇十题用到的运算只有异或、与、移位和取反
    这几种，但每题的突破口都是「把十进制数重新看成一条独立的位串」。刷位运算题，先问
    「这些位各自携带什么信息、哪些位在所有元素里保持一致」，答案往往就出来了。
