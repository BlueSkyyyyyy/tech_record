# 字符串：反转、分组反转与单词翻转

字符串题看起来花样很多，但拆开看只有两条主线：一是**把字符串当成字符数组**，用双指针、
原地交换等数组技巧处理（反转、去重、压缩）；二是**按单词或子串切分**，先拆成若干块、再按
规则重组。两条主线之间还能互相搭桥——例如「翻转单词」就是把整串当成数组先整体反转，再按
单词边界做局部处理。

而这两条线里出现频率最高、也最值得先掌握的动作就是**反转**。它短小、无脑、几乎不会写错，
却可以当作积木反复使用：反转整串、反转一段、反转再反转来「抵消」掉多余的那次。本篇先用
三道基础题把「反转」这块积木立起来——344 教你原地反转一段，541 教你在按长度分组时反转，
151 教你把「整体反转 + 局部再反转」组合起来解决单词级问题。

| 模式 | 题目 | 难度 |
|---|---|---|
| 模式一：对撞双指针原地反转 | 344. 反转字符串 | 简单 |
| 模式二：按固定分组长度的反转 | 541. 反转字符串 II | 简单 |
| 模式三：先整体反转，再逐个单词反转 | 151. 翻转字符串里的单词 | 中等 |

这三题的关系是层层递进的：344 给出「反转一段」的最小模板；541 把它套进一个按 `2k` 跳跃
的外层循环；151 则把「整体反转」和「逐词反转」两次调用拼在一起。读完请特别记住最后一条：
**两次反转可以互相抵消**，这是后面循环移位、局部翻转一类题的通用钥匙。

## 模式一：对撞双指针原地反转

**适用信号**：要改变一段连续元素的顺序，且要求原地进行、不额外分配等长空间。

**核心动作**：左右两指针从两端向中间靠拢，交换所指元素后同步内移，直到相遇或交错。每对
元素只交换一次，因此是线性的。

### 344. 反转字符串（简单）

**题目**：给定一个字符数组 `s`，原地反转它，要求额外空间为 O(1)。

**思路**：

用 `left`、`right` 两个指针分别指向首尾，交换它们指向的字符，然后 `left++`、`right--`，
直到 `left >= right` 停止。循环结束时，前半段和后半段已经一一对调完成。

**为什么用对撞双指针而不是新数组**：题目明确要求原地修改。反转的本质是「第 `i` 个字符与
倒数第 `i` 个字符互换」，两端是天然对称的，所以从两头同时出发、各管一半最自然；交换完
中间那对之后没有元素再需要移动，直接停下即可。这样既满足原地要求，也只用了一个临时变量。

**为什么循环条件是 `left < right` 而不是 `left <= right`**：当两指针相遇（奇数长度）或交错
（偶数长度）时，剩下的元素已经在自己该在的位置上，再交换一次等于自己和自己换，既没必要，
对于 `left == right` 的奇数中点更是纯粹的空转。用严格小于可以把这两种情况一起排除。

**代码**（完整可运行版见 `src/string/reverse_string.py` / `.cpp`）：

```python
def reverse_string(s):
    left, right = 0, len(s) - 1
    while left < right:
        s[left], s[right] = s[right], s[left]
        left += 1
        right -= 1
```

```cpp
void reverseString(std::vector<char> &s) {
    int left = 0;
    int right = static_cast<int>(s.size()) - 1;
    while (left < right) {
        std::swap(s[left], s[right]);
        ++left;
        --right;
    }
}
```

- **复杂度**：时间 O(n)（每对元素交换一次），空间 O(1)。
- **易错点**：Python 的 `str` 不可变，不能直接对字符串做本题；这里传入的是字符列表
  `list[str]`（`list("hello")`）。C++ 参数要用引用 `std::vector<char> &`，若写成传值则改的
  是副本、调用方看不到效果。交换后两指针都要动，只动一个会死循环。
- **相似题**：541. 反转字符串 II（把「反转一段」套进分组循环，见下）；
  151. 翻转字符串里的单词（先整体反转，见下）；189. 轮转数组（数组的「先整体反转、再分段
  反转」，见数组与双指针篇）；125. 验证回文串（对撞双指针只比较不交换，见数组与双指针篇）。

## 模式二：按固定分组长度的反转

**适用信号**：字符串要按某个固定周期（如每 `2k` 个字符）分段，每段只处理其中一部分，且
各段规则相同。

**核心动作**：外层循环**按周期步长跳跃**，直接落到每一段的起点；段内要处理的区间用
`min` 封住右端，一次性兼容「够长」和「不足」两种边界，不在循环里写多个分支。

### 541. 反转字符串 II（简单）

**题目**：给定字符串 `s` 和整数 `k`，从开头起每 `2k` 个字符为一组，反转每组的前 `k` 个
字符：若剩余字符不足 `k` 个，就把剩下的全部反转；若剩余字符在 `[k, 2k)` 之间，只反转前
`k` 个，其余保持原样。返回处理后的字符串。

**思路**：

外层用 `for i in range(0, n, 2*k)` 直接跳到每组的起点 `i`。对每个 `i`，这一组需要反转的
区间是 `[i, min(i + k, n) - 1]`，区间内部复用 344 的对撞双指针交换。

**为什么右端用 `min` 就够了**：题目其实分三种情况，但它们只差「右端取到哪」。当
`i + k <= n` 时，`min(i + k, n) = i + k`，正好反转 `k` 个字符（覆盖「正常组」和「剩余在
`[k, 2k)` 之间」两种情形）；当 `i + k > n` 时，`min` 把右端截到 `n`，等价于「把剩余不足 `k`
个字符全部反转」。一个 `min` 同时表达了两种边界，省掉了 `if/else`，也就不容易漏分支。

**为什么步长是 `2k` 而不是 `k`**：每 `2k` 个字符里只有前 `k` 个要反转，后 `k` 个要**原样
保留**。若步长写成 `k`，就会把本该跳过的那 `k` 个也当成新一段的开头，反转范围整个错位。

**代码**（`src/string/reverse_string_ii.py` / `.cpp`）：

```python
def reverse_str(s, k):
    chars = list(s)
    n = len(chars)
    for i in range(0, n, 2 * k):
        left = i
        right = min(i + k, n) - 1
        while left < right:
            chars[left], chars[right] = chars[right], chars[left]
            left += 1
            right -= 1
    return "".join(chars)
```

```cpp
std::string reverseStr(std::string s, int k) {
    int n = static_cast<int>(s.size());
    for (int i = 0; i < n; i += 2 * k) {
        int left = i;
        int right = std::min(i + k, n) - 1;
        while (left < right) {
            std::swap(s[left], s[right]);
            ++left;
            --right;
        }
    }
    return s;
}
```

- **复杂度**：时间 O(n)（每个字符最多被交换一次），空间 O(n)（Python 字符列表）或 O(1)
  （C++ 原地）。
- **易错点**：步长是 `2 * k`，写成 `k` 会把后半段误反转；右端是 `min(i + k, n) - 1`，
  先 `min` 再减 1，顺序不能反（否则当 `i + k > n` 时右端会越界）；区间是左闭右闭，所以
  `while left < right`；`k = 1` 时任何字符都只有自己一段，结果应与原串相同。
- **相似题**：344. 反转字符串（段内反转的模板本体，见上）；557. 反转字符串中的单词 III
  （把「按固定长度分组」换成「按空格分词」，对每个词内部反转，见字符串后续）；
  345. 反转字符串中的元音字母（对撞双指针交换，但只交换符合条件的字符）。

## 模式三：先整体反转，再逐个单词反转

**适用信号**：要求颠倒「块（单词）」的顺序，但每块内部的元素顺序不变，且块之间可能有
多余的分隔符需要规整。

**核心动作**：用「两次反转」把顺序翻一次：先整体反转，把块的顺序颠倒（但块内也被连带颠倒
了），再对每块单独反转一次，把块内的顺序复原。两次反转中作用在「块内」的那两次互相抵消，
只留下块顺序被颠倒的结果。

### 151. 翻转字符串里的单词（中等）

**题目**：给定字符串 `s`，翻转其中单词的顺序。单词由非空格字符组成，单词之间可能有多个
空格。要求结果中单词之间只用一个空格隔开，且不含首尾空格。

**思路**：

把整串拆成三步处理：

1. **整体反转**整个字符序列。此时单词的先后顺序被颠倒，但每个单词内部的字母也被颠倒了。
2. **压缩空格**：从左往右读单词，一边读一边把需要的字符写到前面（覆盖掉多余空格）。读到
   新单词时若前面已经写过内容，就先补一个空格。
3. **逐个单词再反转一次**：写每个单词的过程中，把写入的那一段区间翻转，复原单词内部顺序。

**为什么两次反转是对的**：整体反转对「单词内部」和「单词之间」各做了一次颠倒。后面再对
每个单词做一次反转，单词内部就翻正了（两次颠倒抵消），而单词之间的顺序只被整体反转颠倒
过一次、没有再被动过，所以最终正好是「单词顺序颠倒、单词内部不变」。这正是题目要的效果。

**为什么能就地压缩空格**：写入位置 `write` 永远不超过读取位置 `i`（压缩只会删掉多余空格，
不会让内容变长），所以把 `s[i]` 写到 `s[write]` 不会覆盖还没读到的字符。读完所有单词后，
`write` 就是有效结果的长度，截取前 `write` 个字符即可，首尾多余空格自然被丢弃。

**代码**（`src/string/reverse_words_in_a_string.py` / `.cpp`）：

```python
def reverse_words(s):
    chars = list(s)
    n = len(chars)

    def reverse(lo, hi):
        while lo < hi:
            chars[lo], chars[hi] = chars[hi], chars[lo]
            lo += 1
            hi -= 1

    reverse(0, n - 1)

    write = 0
    i = 0
    while i < n:
        if chars[i] != " ":
            if write > 0:
                chars[write] = " "
                write += 1
            start = write
            while i < n and chars[i] != " ":
                chars[write] = chars[i]
                write += 1
                i += 1
            reverse(start, write - 1)
        else:
            i += 1
    return "".join(chars[:write])
```

```cpp
std::string reverseWords(std::string s) {
    int n = static_cast<int>(s.size());
    std::reverse(s.begin(), s.end());

    int write = 0;
    for (int i = 0; i < n; ++i) {
        if (s[i] != ' ') {
            if (write != 0) s[write++] = ' ';
            int start = write;
            while (i < n && s[i] != ' ') {
                s[write++] = s[i++];
            }
            std::reverse(s.begin() + start, s.begin() + write);
        }
    }
    return s.substr(0, write);
}
```

- **复杂度**：时间 O(n)（整体反转、压缩、逐词反转各扫一遍，仍是线性），空间 O(n)（Python
  字符列表）或 O(1) 额外空间（C++ 全程在原 `std::string` 上操作，最后只截一个子串）。
- **易错点**：**只有前面已经写过内容时才补空格**（判断 `write > 0`），否则结果会带首空格；
  压缩时的边界 `s[i] != ' '` 要写成循环条件，连续空格才能一次跳过；`reverse(start, write-1)`
  反转的是**写入区间**而不是原区间；整串为空或全是空格时，`write` 为 0，返回空串，
  不能让它输出一个空格。
- **相似题**：344. 反转字符串（提供「反转一段」的模板，见模式一）；186. 反转字符串里的
  单词 II（在字符数组上原地做同一件事，不要求压缩空格）；189. 轮转数组（同样是两次反转
  抵消：先整体反转、再分别反转两段，见数组与双指针篇）；557. 反转字符串中的单词 III
  （只反转每个单词内部、不调整单词顺序，「逐词反转」这一半动作的单独练习）。

## 规律总结

1. **反转是最小的积木**：给定区间 `[lo, hi]`，用对撞双指针 `while lo < hi` 交换内移即可。
   把这段逻辑抽成一个 `reverse(lo, hi)` 函数，后面所有题都只是「调用它几次、调用在哪一段」
   的区别。344 是它的本体，541 和 151 都是在它外面加了一层循环。

2. **涉及下标的循环，先想清楚三件事**：区间是**闭**还是**开**、指针**从哪开始**、**走到
   哪停**。344 用闭区间 `[0, n-1]` 配 `while left < right`；541 的右端用 `min(i + k, n) - 1`
   封顶；151 的 `reverse` 用闭区间。写错一个端点，往往就是差一或越界。

3. **边界交给 `min` / `max`，分支就变少**：541 的三种情况（够长、剩 `[k, 2k)`、剩不足 `k`）
   本质只差右端取值，用 `min(i + k, n) - 1` 一次表达完，比写三段 `if` 更不容易漏。凡遇到
   「最后一段可能不够长」的题，优先考虑用截断代替分支。

4. **步长决定分组**：按周期处理时，外层步长就是**周期**本身（541 是 `2k`，不是 `k`）。
   步长选错会让「该跳过的部分」和「该处理的部分」错位，是这类题最常见的翻车点。

5. **两次反转可以互相抵消**：对同一段先整体反转、再对其中每个小块反转，块内顺序会被复原，
   只留下块与块的顺序被颠倒（151）。反过来，先整体反转、再分别反转前后两段，就能实现
   循环移位（189 轮转数组）。记住这个「翻转两次 = 换一种排列」的直觉，很多题能秒杀。

6. **原地操作用 `write` 指针压缩**：当结果只会比原数据更短（去空格、去重复）时，用一个
   只前进、不后退的 `write` 指针把要保留的内容写到前面，读指针 `i` 只增不减，`write <= i`
   保证不覆盖未读数据，最后取前 `write` 个字符即可。这是数组/字符串「原地筛选」的通用套路。

7. **字符串题先问一句「要不要保留原串」**：Python 的 `str` 不可变，凡是要原地改就得先转成
   `list(str)`；C++ 的 `std::string` 可原地改。若题目允许额外空间，Python 里 `" ".join(
   s.split()[::-1])` 这种一行写法也很常见——但理解底层的两次反转，才能在要求 O(1) 空间时
   不被卡住。
