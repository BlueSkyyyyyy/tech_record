# 字符串：反转、子串匹配与公共前缀

字符串题看起来花样很多，但拆开看只有两条主线：一是**把字符串当成字符数组**，用双指针、
原地交换等数组技巧处理（反转、去重、压缩）；二是**在字符串里做查找与匹配**（找子串、
判周期、求公共前缀）。两条主线之间还能互相搭桥——例如「翻转单词」就是把整串当成数组先
整体反转，再按单词边界做局部处理；而查找类问题一旦用上「复用已匹配信息」的思想，就能从
暴力 O(n·m) 降到线性。

反转这条线短小、几乎不会写错，却可以当作积木反复使用：反转整串、反转一段、反转再反转来
「抵消」掉多余的那次。本篇先用四道题把它立起来——344 原地反转一段，541 按长度分组反转，
151 把「整体反转 + 局部再反转」组合起来翻转单词，557 则只在每个单词内部反转、保持单词
顺序。随后进入查找主线：28 用 KMP 求第一个匹配下标，459 借它判断重复子串，14 求一组
字符串的最长公共前缀。

| 模式 | 题目 | 难度 |

前四题是「反转」的四种用法，层层递进：344 给出「反转一段」的最小模板；541 把它套进按
`2k` 跳跃的外层循环；151 把「整体反转」和「逐词反转」两次调用拼在一起；557 只需要 151
的后半截。读完请特别记住：**两次反转可以互相抵消**，这是后面循环移位、局部翻转一类题的
通用钥匙。后三题则围绕「怎么在串里找东西」：KMP 的 `lps` 数组是核心，它既能加速匹配，
也能顺手给出字符串的周期。

## 模式一：对撞双指针原地反转

**适用信号**：要改变一段连续元素的顺序，且要求原地进行、不额外分配等长空间。

**核心动作**：左右两指针从两端向中间靠拢，交换所指元素后同步内移，直到相遇或交错。每对
元素只交换一次，因此是线性的。

### 344. 反转字符串（简单）

**题目**：给定一个字符数组 `s`，原地反转它，要求额外空间为 O(1)。

**思路**：

用 `left`、`right` 两个指针分别指向首尾，交换它们指向的字符，然后 `left++`、`right--`，
直到 `left >= right` 停止。循环结束时，前半段和后半段已经一一对调完成。

**为什么用对撞双指针而不是新数组**：题目明确要求原地修改。反转的本质是「第 `i` 个字符与
倒数第 `i` 个字符互换」，两端是天然对称的，所以从两头同时出发、各管一半最自然；交换完
中间那对之后没有元素再需要移动，直接停下即可。这样既满足原地要求，也只用了一个临时变量。

**为什么循环条件是 `left < right` 而不是 `left <= right`**：当两指针相遇（奇数长度）或交错
（偶数长度）时，剩下的元素已经在自己该在的位置上，再交换一次等于自己和自己换，既没必要，
对于 `left == right` 的奇数中点更是纯粹的空转。用严格小于可以把这两种情况一起排除。

**代码**（完整可运行版见 `src/string/reverse_string.py` / `.cpp`）：

```python
def reverse_string(s):
    left, right = 0, len(s) - 1
    while left < right:
        s[left], s[right] = s[right], s[left]
        left += 1
        right -= 1
```

```cpp
void reverseString(std::vector<char> &s) {
    int left = 0;
    int right = static_cast<int>(s.size()) - 1;
    while (left < right) {
        std::swap(s[left], s[right]);
        ++left;
        --right;
    }
}
```

- **复杂度**：时间 O(n)（每对元素交换一次），空间 O(1)。
- **易错点**：Python 的 `str` 不可变，不能直接对字符串做本题；这里传入的是字符列表
  `list[str]`（`list("hello")`）。C++ 参数要用引用 `std::vector<char> &`，若写成传值则改的
  是副本、调用方看不到效果。交换后两指针都要动，只动一个会死循环。
- **相似题**：541. 反转字符串 II（把「反转一段」套进分组循环，见下）；
  151. 翻转字符串里的单词（先整体反转，见下）；189. 轮转数组（数组的「先整体反转、再分段
  反转」，见数组与双指针篇）；125. 验证回文串（对撞双指针只比较不交换，见数组与双指针篇）。

## 模式二：按固定分组长度的反转

**适用信号**：字符串要按某个固定周期（如每 `2k` 个字符）分段，每段只处理其中一部分，且
各段规则相同。

**核心动作**：外层循环**按周期步长跳跃**，直接落到每一段的起点；段内要处理的区间用
`min` 封住右端，一次性兼容「够长」和「不足」两种边界，不在循环里写多个分支。

### 541. 反转字符串 II（简单）

**题目**：给定字符串 `s` 和整数 `k`，从开头起每 `2k` 个字符为一组，反转每组的前 `k` 个
字符：若剩余字符不足 `k` 个，就把剩下的全部反转；若剩余字符在 `[k, 2k)` 之间，只反转前
`k` 个，其余保持原样。返回处理后的字符串。

**思路**：

外层用 `for i in range(0, n, 2*k)` 直接跳到每组的起点 `i`。对每个 `i`，这一组需要反转的
区间是 `[i, min(i + k, n) - 1]`，区间内部复用 344 的对撞双指针交换。

**为什么右端用 `min` 就够了**：题目其实分三种情况，但它们只差「右端取到哪」。当
`i + k <= n` 时，`min(i + k, n) = i + k`，正好反转 `k` 个字符（覆盖「正常组」和「剩余在
`[k, 2k)` 之间」两种情形）；当 `i + k > n` 时，`min` 把右端截到 `n`，等价于「把剩余不足 `k`
个字符全部反转」。一个 `min` 同时表达了两种边界，省掉了 `if/else`，也就不容易漏分支。

**为什么步长是 `2k` 而不是 `k`**：每 `2k` 个字符里只有前 `k` 个要反转，后 `k` 个要**原样
保留**。若步长写成 `k`，就会把本该跳过的那 `k` 个也当成新一段的开头，反转范围整个错位。

**代码**（`src/string/reverse_string_ii.py` / `.cpp`）：

```python
def reverse_str(s, k):
    chars = list(s)
    n = len(chars)
    for i in range(0, n, 2 * k):
        left = i
        right = min(i + k, n) - 1
        while left < right:
            chars[left], chars[right] = chars[right], chars[left]
            left += 1
            right -= 1
    return "".join(chars)
```

```cpp
std::string reverseStr(std::string s, int k) {
    int n = static_cast<int>(s.size());
    for (int i = 0; i < n; i += 2 * k) {
        int left = i;
        int right = std::min(i + k, n) - 1;
        while (left < right) {
            std::swap(s[left], s[right]);
            ++left;
            --right;
        }
    }
    return s;
}
```

- **复杂度**：时间 O(n)（每个字符最多被交换一次），空间 O(n)（Python 字符列表）或 O(1)
  （C++ 原地）。
- **易错点**：步长是 `2 * k`，写成 `k` 会把后半段误反转；右端是 `min(i + k, n) - 1`，
  先 `min` 再减 1，顺序不能反（否则当 `i + k > n` 时右端会越界）；区间是左闭右闭，所以
  `while left < right`；`k = 1` 时任何字符都只有自己一段，结果应与原串相同。
- **相似题**：344. 反转字符串（段内反转的模板本体，见上）；557. 反转字符串中的单词 III
  （把「按固定长度分组」换成「按空格分词」，对每个词内部反转，见字符串后续）；
  345. 反转字符串中的元音字母（对撞双指针交换，但只交换符合条件的字符）。

## 模式三：先整体反转，再逐个单词反转

**适用信号**：要求颠倒「块（单词）」的顺序，但每块内部的元素顺序不变，且块之间可能有
多余的分隔符需要规整。

**核心动作**：用「两次反转」把顺序翻一次：先整体反转，把块的顺序颠倒（但块内也被连带颠倒
了），再对每块单独反转一次，把块内的顺序复原。两次反转中作用在「块内」的那两次互相抵消，
只留下块顺序被颠倒的结果。

### 151. 翻转字符串里的单词（中等）

**题目**：给定字符串 `s`，翻转其中单词的顺序。单词由非空格字符组成，单词之间可能有多个
空格。要求结果中单词之间只用一个空格隔开，且不含首尾空格。

**思路**：

把整串拆成三步处理：

1. **整体反转**整个字符序列。此时单词的先后顺序被颠倒，但每个单词内部的字母也被颠倒了。
2. **压缩空格**：从左往右读单词，一边读一边把需要的字符写到前面（覆盖掉多余空格）。读到
   新单词时若前面已经写过内容，就先补一个空格。
3. **逐个单词再反转一次**：写每个单词的过程中，把写入的那一段区间翻转，复原单词内部顺序。

**为什么两次反转是对的**：整体反转对「单词内部」和「单词之间」各做了一次颠倒。后面再对
每个单词做一次反转，单词内部就翻正了（两次颠倒抵消），而单词之间的顺序只被整体反转颠倒
过一次、没有再被动过，所以最终正好是「单词顺序颠倒、单词内部不变」。这正是题目要的效果。

**为什么能就地压缩空格**：写入位置 `write` 永远不超过读取位置 `i`（压缩只会删掉多余空格，
不会让内容变长），所以把 `s[i]` 写到 `s[write]` 不会覆盖还没读到的字符。读完所有单词后，
`write` 就是有效结果的长度，截取前 `write` 个字符即可，首尾多余空格自然被丢弃。

**代码**（`src/string/reverse_words_in_a_string.py` / `.cpp`）：

```python
def reverse_words(s):
    chars = list(s)
    n = len(chars)

    def reverse(lo, hi):
        while lo < hi:
            chars[lo], chars[hi] = chars[hi], chars[lo]
            lo += 1
            hi -= 1

    reverse(0, n - 1)

    write = 0
    i = 0
    while i < n:
        if chars[i] != " ":
            if write > 0:
                chars[write] = " "
                write += 1
            start = write
            while i < n and chars[i] != " ":
                chars[write] = chars[i]
                write += 1
                i += 1
            reverse(start, write - 1)
        else:
            i += 1
    return "".join(chars[:write])
```

```cpp
std::string reverseWords(std::string s) {
    int n = static_cast<int>(s.size());
    std::reverse(s.begin(), s.end());

    int write = 0;
    for (int i = 0; i < n; ++i) {
        if (s[i] != ' ') {
            if (write != 0) s[write++] = ' ';
            int start = write;
            while (i < n && s[i] != ' ') {
                s[write++] = s[i++];
            }
            std::reverse(s.begin() + start, s.begin() + write);
        }
    }
    return s.substr(0, write);
}
```

- **复杂度**：时间 O(n)（整体反转、压缩、逐词反转各扫一遍，仍是线性），空间 O(n)（Python
  字符列表）或 O(1) 额外空间（C++ 全程在原 `std::string` 上操作，最后只截一个子串）。
- **易错点**：**只有前面已经写过内容时才补空格**（判断 `write > 0`），否则结果会带首空格；
  压缩时的边界 `s[i] != ' '` 要写成循环条件，连续空格才能一次跳过；`reverse(start, write-1)`
  反转的是**写入区间**而不是原区间；整串为空或全是空格时，`write` 为 0，返回空串，
  不能让它输出一个空格。
- **相似题**：344. 反转字符串（提供「反转一段」的模板，见模式一）；186. 反转字符串里的
  单词 II（在字符数组上原地做同一件事，不要求压缩空格）；189. 轮转数组（同样是两次反转
  抵消：先整体反转、再分别反转两段，见数组与双指针篇）；557. 反转字符串中的单词 III
  （只反转每个单词内部、不调整单词顺序，「逐词反转」这一半动作的单独练习，见下）。

## 模式四：按分隔符切分后块内反转

**适用信号**：题目的处理单位是「块」（单词、字段、某段区间），块内部要按某种规则变换，
但块与块之间的顺序和分隔符位置都保持不变。

**核心动作**：扫描时用 `start` 记住当前块的左端点，一旦遇到分隔符（或扫完整串），就把
`[start, i-1]` 这一段交给「反转一段」的模板处理，再把 `start` 挪到分隔符之后。

### 557. 反转字符串中的单词 III（简单）

**题目**：给定字符串 `s`（单词之间用单个空格分隔），反转每个单词内部的字符顺序，同时保持
单词之间的顺序和空格位置不变。

**思路**：

与 151 不同，这里单词顺序**不变**，所以不需要「整体反转」，只要找出每个单词的区间再各自
反转即可。用 `start` 记录当前单词起点，从左往右扫；每遇到一个空格（或扫到串尾），就把
区间 `[start, i-1]` 反转，然后把 `start` 移到 `i+1`。

**为什么扫描要走到 `n` 而不是停在最后一个字符**：最后一个单词后面没有空格，如果只靠
「遇到空格」触发结算，末尾单词会被漏掉。让 `i` 走到 `n` 时也触发一次，就能把末尾单词一并
处理，不用额外写收尾分支。

**为什么不真的 `split` 再 `join`**：`split` 会分配一批子串、`join` 再拼回去，空间是
O(n) 的额外开销。边扫描边在原地改写，是「按分隔符处理」更省内存的写法，也更能迁移到
不允许创建新数组的场景。

**代码**（`src/string/reverse_words_iii.py` / `.cpp`）：

```python
def reverse_words_iii(s):
    chars = list(s)
    n = len(chars)

    def reverse(lo, hi):
        while lo < hi:
            chars[lo], chars[hi] = chars[hi], chars[lo]
            lo += 1
            hi -= 1

    start = 0
    for i in range(n + 1):
        if i == n or chars[i] == " ":
            reverse(start, i - 1)
            start = i + 1
    return "".join(chars)
```

```cpp
std::string reverseWordsIII(std::string s) {
    int n = static_cast<int>(s.size());
    int start = 0;
    for (int i = 0; i <= n; ++i) {
        if (i == n || s[i] == ' ') {
            std::reverse(s.begin() + start, s.begin() + i);
            start = i + 1;
        }
    }
    return s;
}
```

- **复杂度**：时间 O(n)（每个字符只被反转一次），空间 O(n)（Python 字符列表）或 O(1)
  额外空间（C++ 原地）。
- **易错点**：循环上界是 `n + 1` 个位置（`range(n + 1)` / `i <= n`），多出来的第 `n` 位
  用来结算最后一个单词；反转区间是 `[start, i-1]`，别把空格也翻进去；`start = i + 1`
  要放在结算之后，且注意是跳过空格的那一格。
- **相似题**：151. 翻转字符串里的单词（还要调整单词顺序并压缩空格，见模式三）；344. 反转
  字符串（块内反转的模板本体）；541. 反转字符串 II（块的边界由长度而非空格决定，见模式二）。

## 模式五：子串匹配与 KMP

**适用信号**：要在一个长串里找某个模式串第一次（或每一次）出现的位置，且串长很大、不能
承受暴力匹配的最坏情况。

**核心动作**：先对模式串求**前缀函数** `lps`，记录每个前缀「最长的、既是真前缀又是真后缀」
的长度；匹配时文本指针只前进不回退，失配就把模式串指针按 `lps` 回退。

### 28. 找出字符串中第一个匹配项的下标（中等）

**题目**：给定 `haystack` 与 `needle`，返回 `needle` 在 `haystack` 中第一次出现的下标；
不存在返回 `-1`。约定 `needle` 为空串时返回 `0`。

**思路**：

暴力匹配每次失配都让模式串从头再来，最坏 O(n·m)。KMP 的想法是：已经匹配上的那一段本身
携带信息，其中「既是前缀又是后缀」的部分可以直接复用，不必从头比较。

先求前缀函数：

```
lps[i] = needle[0..i] 中「最长的真前缀、同时又是真后缀」的长度
```

例如 `needle = "abcabd"`，其 `lps = [0,0,0,1,2,0]`。匹配阶段用 `k` 表示当前已匹配的
模式串长度，文本指针 `i` 单向前进：

- 若 `haystack[i] == needle[k]`，两者一起前进（`k += 1`）；
- 若失配且 `k > 0`，就把 `k` 退到 `lps[k-1]`，意思是「前面这段的公共前后缀仍然匹配，
  从这个位置继续比」，然后重试当前字符；
- 当 `k == m` 时，`i - m + 1` 就是匹配起点。

**为什么 `lps` 能复用**：`lps[k-1]` 是「已经匹配的那段里，最长的、末尾等于开头的部分」。
把模式串右移，让这段后缀对齐到这段前缀上，就能跳过必然匹配的一段，只从失配处接着比。也
正因为文本指针不回退，整个过程才是线性的。

**代码**（`src/string/implement_strstr.py` / `.cpp`）：

```python
def str_str(haystack, needle):
    if needle == "":
        return 0
    n, m = len(haystack), len(needle)

    lps = [0] * m
    k = 0
    for i in range(1, m):
        while k > 0 and needle[i] != needle[k]:
            k = lps[k - 1]
        if needle[i] == needle[k]:
            k += 1
        lps[i] = k

    k = 0
    for i in range(n):
        while k > 0 and haystack[i] != needle[k]:
            k = lps[k - 1]
        if haystack[i] == needle[k]:
            k += 1
            if k == m:
                return i - m + 1
    return -1
```

```cpp
int strStr(const std::string &haystack, const std::string &needle) {
    if (needle.empty()) return 0;
    int n = static_cast<int>(haystack.size());
    int m = static_cast<int>(needle.size());

    std::vector<int> lps(m, 0);
    int k = 0;
    for (int i = 1; i < m; ++i) {
        while (k > 0 && needle[i] != needle[k]) k = lps[k - 1];
        if (needle[i] == needle[k]) ++k;
        lps[i] = k;
    }

    k = 0;
    for (int i = 0; i < n; ++i) {
        while (k > 0 && haystack[i] != needle[k]) k = lps[k - 1];
        if (haystack[i] == needle[k]) {
            ++k;
            if (k == m) return i - m + 1;
        }
    }
    return -1;
}
```

- **复杂度**：时间 O(n + m)，空间 O(m)。
- **易错点**：失配时的回退是 `while` 而不是 `if`（可能连续回退多次）；先写 `while` 再
  写「相等则前进」，顺序反了会漏掉回退后立刻匹配的情况；求 `lps` 时循环从 `i = 1` 开始，
  `lps[0]` 恒为 0；空串约定返回 0，要单独判掉。
- **相似题**：459. 重复的子字符串（同一个 `lps` 数组还能判周期，见模式六）；214. 最短回文串
  （在 `s + '#' + reverse(s)` 上求前缀函数）；1392. 最长快乐前缀（前缀函数直接应用）。

## 模式六：用前缀函数判重复子串

**适用信号**：判断一个字符串是否由某个更短的块循环拼接而成，或要求最小循环节长度。

**核心动作**：对整串求前缀函数，取 `p = lps[n-1]`，则最小周期长度是 `n - p`；只要
`p > 0` 且 `n % (n - p) == 0`，整串就是由该周期重复而成。

### 459. 重复的子字符串（简单）

**题目**：给定非空字符串 `s`，判断它能否由某个子串重复多次（至少两次）拼接而成。

**思路**：

设 `n` 为串长，`p = lps[n-1]` 是 `s` 的最长公共真前后缀长度。那么最小周期长度是
`n - p`。若它能整除 `n`，整个串就由前 `n - p` 个字符重复 `n / (n - p)` 次组成。

**为什么这样成立**：`lps[n-1] = p` 说明 `s` 的前 `p` 个字符与后 `p` 个字符完全相同，
相当于把整串「向左平移」`n - p` 位后仍然自洽。若 `n - p` 整除 `n`，这种平移就不会产生
错位，整串被长度 `n - p` 的块循环铺满。

**为什么必须同时判 `p > 0`**：若 `p == 0`，则 `n - p = n`，而 `n % n == 0` 恒成立，
会把「自己算重复一次」误判为答案。先用 `p > 0` 挡掉这种情况，才表示真的存在更短的周期。

**另一种等价写法**：把 `s` 拼成 `s + s`，去掉首尾各一个字符后在其中查找 `s`。若还能
找到，说明存在一个非自身的循环位移，即由更小的块重复而成。用 KMP 思路写就是上面的前缀
函数版本，与 28 共用同一套模板。

**代码**（`src/string/repeated_substring_pattern.py` / `.cpp`）：

```python
def repeated_substring_pattern(s):
    n = len(s)
    if n == 0:
        return False

    lps = [0] * n
    k = 0
    for i in range(1, n):
        while k > 0 and s[i] != s[k]:
            k = lps[k - 1]
        if s[i] == s[k]:
            k += 1
        lps[i] = k

    p = lps[-1]
    return p > 0 and n % (n - p) == 0
```

```cpp
bool repeatedSubstringPattern(const std::string &s) {
    int n = static_cast<int>(s.size());
    if (n == 0) return false;

    std::vector<int> lps(n, 0);
    int k = 0;
    for (int i = 1; i < n; ++i) {
        while (k > 0 && s[i] != s[k]) k = lps[k - 1];
        if (s[i] == s[k]) ++k;
        lps[i] = k;
    }

    int p = lps[n - 1];
    return p > 0 && n % (n - p) == 0;
}
```

- **复杂度**：时间 O(n)，空间 O(n)。
- **易错点**：`p > 0` 那一半判断不能省；整除用 `n % (n - p) == 0`，除数为 `n - p`
  而不是 `p`；`s` 极短（如 `"a"`）时 `p = 0`，应返回 `False`。
- **相似题**：28. 找出字符串中第一个匹配项的下标（KMP 模板本体，见模式五）；1392. 最长
  快乐前缀（同款前缀函数）；常见的 `(s + s).find(s, 1)` 解法是本题的另一种思路。

## 模式七：纵向扫描求公共前缀

**适用信号**：给一组字符串或多个序列，要找它们从头开始「最大公共的部分」，一旦某个位置
不齐就可以立刻停止。

**核心动作**：拿第一个作为基准，按下标一列一列地检查其余每个是否都相同；遇到不齐就返回
已确认的前缀。逐列检查天然支持「早停」。

### 14. 最长公共前缀（简单）

**题目**：给定字符串数组 `strs`，返回所有字符串的最长公共前缀；若不存在公共前缀返回空串。

**思路**：

以第一个字符串为「基准列」，逐个下标 `i` 检查：取出 `strs[0][i]`，看其余每个字符串的
第 `i` 个字符是否都等于它。若某个字符串已有 `i == len(s)`（它比前缀短）或字符不同，就
返回 `strs[0][:i]`；所有列都比完仍无差异，则答案是整个 `strs[0]`。

**为什么以第一串为基准是安全的**：公共前缀必然也是第一串的前缀，所以它的长度不会超过
第一串。沿第一串的每一列向外比对，只需考虑「不齐」这一个终止条件，不必额外处理前缀比
基准还长的情况。

**为什么用纵向而不是两两归并**：纵向扫描一旦某列不齐就立刻返回，通常比把所有字符串都
处理完更早退出；两两取公共前缀（横向扫描）也能得到同样答案，但中间结果要反复传递。两者
最坏复杂度同阶，纵向写法更简短。

**代码**（`src/string/longest_common_prefix.py` / `.cpp`）：

```python
def longest_common_prefix(strs):
    if not strs:
        return ""
    for i in range(len(strs[0])):
        ch = strs[0][i]
        for s in strs[1:]:
            if i == len(s) or s[i] != ch:
                return strs[0][:i]
    return strs[0]
```

```cpp
std::string longestCommonPrefix(const std::vector<std::string> &strs) {
    if (strs.empty()) return "";
    int firstLen = static_cast<int>(strs[0].size());
    for (int i = 0; i < firstLen; ++i) {
        char ch = strs[0][i];
        for (std::size_t j = 1; j < strs.size(); ++j) {
            if (i == static_cast<int>(strs[j].size()) || strs[j][i] != ch) {
                return strs[0].substr(0, i);
            }
        }
    }
    return strs[0];
}
```

- **复杂度**：时间 O(所有字符总数)（最坏情况每列都要检查所有串，恰好等于总长度），
  空间 O(1)。
- **易错点**：先判 `i == len(s)` 再取 `s[i]`，否则短串会越界；输入为空数组要单独返回
  空串（`strs[0]` 会崩）；所有串完全相同时返回基准串本身，不要漏掉循环外的 `return`。
- **相似题**：28. 找出字符串中第一个匹配项的下标（都是「在串上做匹配」，但 KMP 面向
  「模式串在文本里出现」，本题面向「多个串的共同开头」）；5. 最长回文子串（也是从中心
  或两端向两边扩展的比对，见动态规划篇）；分治版 14（把数组二分后合并前缀）可作为练习。

## 与其它篇的交叉

字符串题的很多解法，其实是别的篇里模板在字符串场景下的「换皮」。下面三题正文分别在其它
篇，这里只点出它们与本篇的关系，方便串起知识网。

- **125. 验证回文串（简单）**——「对撞双指针只比较、不交换」的最小例子。它和 344 用的是
  同一副骨架，区别只在 344 要交换、它只判断是否相等；处理时先跳过非字母数字字符、再统一
  大小写。详见「数组与双指针」篇。

- **394. 字符串解码（中等）**——处理 `k[encoded]` 这种嵌套结构。外层字符串和重复次数需要
  「后进先出」，所以用栈保存上下文，遇到 `]` 再弹栈拼接。它是「栈处理嵌套结构」在字符串
  上的典型应用，详见「栈与单调栈」篇。

- **5. 最长回文子串（中等）**——求最长的回文连续子串。中心扩展法把每个位置（或每对相邻
  位置）当中心向两边扩，最坏 O(n²) 但在实际数据上很快；也可用区间 DP 统一处理回文类问题。
  详见「动态规划」篇。

把这几题放在一起看，会发现：**反转 / 双指针 / 栈 / 区间扩展**这些模板并不属于某个单独
的数据结构，而是同一批「处理序列」的动作；字符串只是它们最常出现的舞台之一。

## 规律总结

1. **反转是最小的积木**：给定区间 `[lo, hi]`，用对撞双指针 `while lo < hi` 交换内移即可。
   把这段逻辑抽成一个 `reverse(lo, hi)` 函数，后面所有题都只是「调用它几次、调用在哪一段」
   的区别。344 是它的本体，541 和 151 都是在它外面加了一层循环。

2. **涉及下标的循环，先想清楚三件事**：区间是**闭**还是**开**、指针**从哪开始**、**走到
   哪停**。344 用闭区间 `[0, n-1]` 配 `while left < right`；541 的右端用 `min(i + k, n) - 1`
   封顶；151 的 `reverse` 用闭区间。写错一个端点，往往就是差一或越界。

3. **边界交给 `min` / `max`，分支就变少**：541 的三种情况（够长、剩 `[k, 2k)`、剩不足 `k`）
   本质只差右端取值，用 `min(i + k, n) - 1` 一次表达完，比写三段 `if` 更不容易漏。凡遇到
   「最后一段可能不够长」的题，优先考虑用截断代替分支。

4. **步长决定分组**：按周期处理时，外层步长就是**周期**本身（541 是 `2k`，不是 `k`）。
   步长选错会让「该跳过的部分」和「该处理的部分」错位，是这类题最常见的翻车点。

5. **两次反转可以互相抵消**：对同一段先整体反转、再对其中每个小块反转，块内顺序会被复原，
   只留下块与块的顺序被颠倒（151）。反过来，先整体反转、再分别反转前后两段，就能实现
   循环移位（189 轮转数组）。记住这个「翻转两次 = 换一种排列」的直觉，很多题能秒杀。

6. **原地操作用 `write` 指针压缩**：当结果只会比原数据更短（去空格、去重复）时，用一个
   只前进、不后退的 `write` 指针把要保留的内容写到前面，读指针 `i` 只增不减，`write <= i`
   保证不覆盖未读数据，最后取前 `write` 个字符即可。这是数组/字符串「原地筛选」的通用套路。

7. **字符串题先问一句「要不要保留原串」**：Python 的 `str` 不可变，凡是要原地改就得先转成
   `list(str)`；C++ 的 `std::string` 可原地改。若题目允许额外空间，Python 里 `" ".join(
   s.split()[::-1])` 这种一行写法也很常见——但理解底层的两次反转，才能在要求 O(1) 空间时
   不被卡住。

8. **按块处理时，把「根号循环」写到 `n + 1`**：557 用 `for i in range(n + 1)` 让「遇到
   空格」和「扫到串尾」共用同一段结算代码，末尾块不用单独收尾。凡是「按分隔符切分、块间
   互不影响」的题，都可以套这个「扫描 → 在分隔符/结尾处结算一块」的骨架。

9. **前缀函数 `lps` 是字符串匹配的万能钥匙**：它能 O(1) 告诉你「已匹配段里可复用的最长
   前后缀」，于是匹配指针不回退（28），也能顺手读出串的最小周期（459）。构造 `lps` 的
   四行模板（`while` 回退 → 相等前进 → 记录）和 28、459 完全一样，背下来即可。

10. **匹配类问题先问「失配后能不能不从头再来」**：暴力匹配的痛点是每次失败都归零。KMP
    的答案是把「已经匹配上的内容」当成资产复用。遇到「模式串在长文本里找位置」「前后缀
    重叠」「循环节」这一类信号，先想前缀函数，而不是直接上两层循环。

11. **比对多个序列时，纵向扫描常常最简**：14 拿第一个当基准、一列一列看，发现不齐立即
    返回，天然支持早停。凡是「多个串/多个数组从开头起的公共部分」，优先考虑纵向扫描；
    两两归并或分治版本可以作为思路拓展，但通常更长。
