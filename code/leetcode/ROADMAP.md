# LeetCode 题解精讲 · 路线图（活文档）

> 目标：把 LeetCode 高频经典题按**数据结构/算法模式**分类，写成**由易到难、相似题成组**的题解专题，
> 每道题讲清「怎么想到 + 复杂度 + 易错点 + 相似题」，并配 **Python 与 C++** 的可运行代码。
> 本专题为长期自驱任务，由 `scripts/autopilot.sh` 驱动（与仓库内其它自驱任务并行）。
>
> **写作原则**：一轮只做一个增量，宁可少而精，不要多而糙。

## 交付物

1. **题解文档** `docs/<NN>-<category>.md`：按模式分组，题内结构固定
   （题目 → 思路含为什么 → 代码 → 复杂度 → 易错点 → 相似题），篇末「规律总结」。
2. **可运行代码** `src/<category>/<problem>.py` 与 `.cpp`：
   每个文件自带 `if __name__ == "__main__"` 自测（Python 用 assert，C++ 用 assert + 退出码）。
3. **博客文章** `content/posts/leetcode-NN-<category>/index.md`，
   用 `{{< lc_include "code/leetcode/docs/....md" >}}` 实时内联题解文档。
4. **导航正确**：分类目录只在文章（content/posts）里用 `relref`；
   被内联的 docs 内**不允许**写短代码（不会二次解析）。不写「上一篇/下一篇」式闲聊，靠主题自动导航。

## 目录约定

```
code/leetcode/
  README.md
  ROADMAP.md                 # 本文件（控制面板）
  docs/<NN>-<category>.md    # 题解正文（内联到博客）
  src/<category>/<problem>.py|.cpp   # 可运行代码 + 自测
  scripts/run_all.py         # 统一自测入口
  scripts/autopilot.sh       # 自驱循环
```

分类 slug（与博客篇号一致）：`array`, `hash`, `sliding-window`, `prefix-sum`, `binary-search`,
`linked-list`, `stack`, `heap`, `binary-tree`, `graph`, `backtracking`, `divide-conquer`,
`dynamic-programming`, `greedy`, `string`, `bit`, `trie`, `math`, `design`, `matrix`, `sort`,
`shortest-path`, `union-find`, `fenwick`, `segment-tree`, `game-theory`, `randomized`,
`geometry`。

## 题量要求

- 每个普通分类 **≥ 10 题**，由易到难；相似题连续成组，并互相交叉引用。
- 大专题（动态规划、图、树、回溯）**题量更多**，可拆多个子篇，每篇都要有「规律总结」。
- 每道题尽量给**多种解法**时，只详展最优解，其余一句话带过（避免篇幅失控）。

## 已知坑

1. **内联 docs 里写短代码无效**：`readFile` + `markdownify` 不会二次解析 `{{< >}}`。站内链接只能写在 `content/posts/*/index.md` 里。
2. **C++ `assert` 的宏坑**：`assert(v == std::vector<int>{1, 2})` 会因 `{}` 里的逗号被当成宏参数而编译失败。
   解决：先把期望值存进变量，再 `assert(got == want)`。
3. **中文与代码块之间留空行**，避免渲染粘连。
4. 题解代码与 `src/` 必须一致；以 `src/` 为准（它经过自测），docs 只做粘贴。
