===== §F 结论 =====
  - §C: 若 bind/bind_bal 的 coal+scalar 明显 > interleave => 发射受限税是 **SM 内**、
        可用角色绑定消除（补 §72.8 缓解(a)）；若仍 ~0.87 => 是 SM 间/HBM 全局现象。
  - bind(naive) 在速率异质混合(equal4/coal+sparse)上 << interleave => 均分 SM 的负载不均代价；
    bind_bal(∝1/每SM速率) 应把它补回。§A placement 行的『不均』应为 0。
