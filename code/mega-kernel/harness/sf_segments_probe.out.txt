=== 2) dense 打包: 4 个不同 per-128-K scale 装进 1 uint32, sf_id 解回 ===
  4 个 per-128 scale : 0.5 2 0.25 4
  host packed uint32 : 0x817D807E
    k_block=0 -> sf_id=0 byte=0x7E want=0x7E OK
    k_block=1 -> sf_id=1 byte=0x80 want=0x80 OK
    k_block=2 -> sf_id=2 byte=0x7D want=0x7D OK
    k_block=3 -> sf_id=3 byte=0x81 want=0x81 OK
  => dense 的 sf_id 是「真地址选择」: PASS (4 byte 互不相同)

=== 3) MoE 打包: 1 个 per-128 scale 复制 4 份, sf_id 空操作 ===
  per-128 scale = 2 -> UE8M0 0x80
  device packed uint32 = 0x80808080 (4 字节全等)
  => sfa_id=sfb_id=k_sub 选哪一字节都一样: PASS (空操作)

=== 5) 转置双射: (i^(lane>>3))*32+lane <-> lane*4+(i^(lane>>3)) 对 4x32 ===
