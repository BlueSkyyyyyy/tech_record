===== §E 结论 =====
  - §C2/§C3: 若同一 Wsm 内 (T,O) 拆分的 bind meas/E spread ~1 => 税只由 Wsm 定、与拆分无关；
        若 2048 处在 T1024/O2 上明显偏离 O8/T256，则 §78.8『2048 未完全解耦』确有其事。
  - §B: 同一 Wsm 内各拆分的 solo 是否一致（合量 Wsm 是否支配单模式吞吐）。
  - §A: bind 在 O=1/2/4/8/16 逐位对 host 参考 => per-SM 原子子段游标在高 O 下正确。
