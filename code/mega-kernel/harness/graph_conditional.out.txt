>> 读法：
>> A: 行程 N 变大时 unroll/cwhile/kinternal 相对 eager 省的是 **launch**；
>>    cwhile 每行程多一次**设备内条件求值 + body 图重新分发**；
>>    kinternal（持久化内核）是下限——同一批 block 内循环，无图/无 node 分发。
>> B: work=0 时每行程成本 = 纯控制；instantiate 时间 unroll 随 N 线性、cwhile 常数。
>> C: 同一张静态图可由**设备侧数据**决定分支——CUDA Graph 对 MPK
>>    「按数据/batch 改图」局限的一条（受限）出路。
