===== §G 结论 =====
  - §C: 若单起点重复跑的 spread>1.02 => bind_insitu 结果不可复现（§75.9 尾巴坐实）。
  - §D/§E: bind_global 的 meas/E 与 bG/org 若 ~1.0 => 多起点追平 oracle、单起点 gap 被收回。
  - §F: 噪声地板 spread 给出评价本身的可分辨下限。
