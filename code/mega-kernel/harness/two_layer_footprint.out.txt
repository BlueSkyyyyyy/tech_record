----+----+-------------+-----------
  1 |   0 |      0.5310 |      1.000x   base (P=1,H=0)

256 | 128 |      2.0149 |      3.795x   both

>> 读法：
>> 定义边际代价：m_code = comp(P=256,H=0)/comp(P=1,H=0)（代码足迹）；
>>              m_reg  = mem(P=1,H=128)/mem(P=1,H=0)（寄存器足迹，作用在访存路径）。
>> B3 的 both 行若 ≈ m_code×m_reg 的加权组合 -> 两笔代价近似独立叠加；
>> 若 B2 里同一个 P 在 H=128（低占用率）下比 H=0 更慢 -> 低占用率放大了取指停顿（交互项）。
>> 核心问题：把重寄存器 task 与大量互异 task body 编进同一 kernel，代价是否只是简单相加。
