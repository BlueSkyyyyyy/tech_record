>> 读法：no-PDL 每 kernel = prologue+crit+tail（严格串行）；
>> PDL 每条链边重叠 min(prologue, tail)，稳态每 kernel = span - min(prologue, tail)，
>> 故 K 大时 speedup 趋 span/(span-min)；A 组(pl=tail) →~2×，B 组(tail=3×pl) →~1.33×。
>> 关键：收益由 min(prologue,tail) 封顶，**不会随 K 无限叠加**——PDL 是 kernel 级流水，
>> 链上仍有 host 逐个 launch、中间量仍可落 HBM，非 MPK 单 kernel 内 SM 级软件流水（§5.3 行 1326–1363）。
