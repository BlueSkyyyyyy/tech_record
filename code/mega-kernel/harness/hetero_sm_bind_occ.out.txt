===== §F 结论 =====
  - §C: 若 bind/interleave 的 meas/E 在三档 O 下**逐行不变** => §73『税是全局』对每 SM
        block 数稳健；若 O↑ 让 coal+scalar 的税消失 => 它是 warp 摊可回收的 SM 内现象。
  - §B: 三档 O 若近似相等 => 复现 §70/§71『吞吐由合量 O·T 定』；块级 prologue 让大 O 略慢
        是次要项。
  - §A: bind O>1 逐位对 host 参考 => per-SM 原子子段游标正确。
