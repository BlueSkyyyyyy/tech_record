===== §F 结论 =====
  - §C2: 若 coal+scalar 的 bind meas/E 随 Wsm↑ **不变** => 『加 warp 摊』不兑现（税是全局的，
        与 §73/§77 一脉）；若随 Wsm↑ 收敛到 1 => 它是 SM 内发射槽/延迟现象、加 warp 可回收。
  - §B: 各模式 solo 随 Wsm 饱和情况（sparse 早饱和、coal/scalar 需更多 warp）。
  - §A: bind 在 O=1/2/4/8 逐位对 host 参考 => per-SM 原子子段游标在高 O 下正确。
