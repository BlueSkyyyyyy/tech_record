>> 读法：关键量是 **sched**（下游何时被调度拿到 SM），不是 rel。
>> block：sched≈A_total（完成即放行，下游 prologue 不能与上游 tail 重叠）；
>> prog_nt：A 不 trigger -> 端口在终止时激活，sched≈A_total；
>> prog：A 在 prologue 后 trigger -> sched≈pro << A_total——**图的 programmatic 边
>>   把下游的调度点前移到了上游完成之前**（下游 prologue 与上游 tail 重叠），
>>   这正是 stream 上 cudaStreamWaitEvent 做不到的（§21）。
>> lce：全体 block 启动即放行，sched≈0。
>> 但 rel（下游 cudaGridDependencySynchronize 返回）恒 ≈ A_total——端口只决定
>>   下游**何时被调度**，不改变 gridDependencySync 等**上游完成**的语义（与 §21 一致）。
>> done 应恒 == iters。
