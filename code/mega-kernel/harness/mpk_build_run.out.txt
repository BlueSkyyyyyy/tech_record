## 一、构建安装（pip install -e .）
# 关键步骤（原生库 build 成功后，唯一失败点是运行期依赖 tg4perfetto@git 的 github 连接超时；
# 改用 PyPI 的 tg4perfetto 后，用 --no-deps --no-build-isolation 完成安装）：
#   git submodule update --init --recursive        # cutlass/json/z3（github 需重试）
#   pip install tg4perfetto                         # PyPI，避开 git 直连
#   pip install 'accelerate==1.8.0' graphviz tqdm protobuf cuda-python fastapi uvicorn 'z3-solver==4.16.0.0'
#   MIRAGE_HOME=/ssd/mirage_mpk_build pip install -e . --no-deps --no-build-isolation
# CMakeLists 的 CMAKE_CUDA_ARCHITECTURES 由 "75;80;86;89;90" 收窄为 "90" 以省编译时间。
#
# 结果（build2.log 尾部）:
