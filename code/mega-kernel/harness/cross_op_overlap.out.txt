>> 读法：
>>  s/b        : barrier 相对 serial —— 单次 launch（消损失二）能带来多少；本区间应≈1.0。
>>  pipe/b     : 细粒度重叠（逐 tile ready）相对算子级屏障的加速（损失一的跨算子形态）。
>>  ideal      : max(Tp(Gp), Tc(Gc)) —— 静态分块 + 完美重叠的理论下界；对比 barrier 看分块值不值。
>>  Section A  : 关键发现是 pipe/b 恒 <1：**静态切 block 的细粒度重叠赢不过算子级屏障**。
>>  Section B  : producer 从访存受限变计算受限后，两阶段抢同一资源，pipe/b 进一步掉到 ~0.4。
>>  Section C  : producer block 太少喂不满 BW、太多挤占 consumer，最优 Gp 仍打不过 barrier。
>>  Section D  : 两阶段时间都随 block 数近似线性 —— 阶段内部并行度不足，切走 block 就等比例变慢，
>>               故「切 block 做跨算子重叠」在固定 SM 的 GPU 上结构性不划算；真正的跨算子重叠要
>>               靠 SM 内**共驻**（warp 特化/时分复用，见 P13-1/P18-1），而不是静态分区。
