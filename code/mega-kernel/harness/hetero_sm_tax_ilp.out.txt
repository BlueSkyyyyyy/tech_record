===== §F 结论 =====
  - §C/§C2: coal+scalar 的绝对 mixed 随 Wsm 单调升、meas/E 与 taxRef 同向；
        scalar+l2res/equal4 若绝对 mixed 跨 Wsm 小变而 meas/E 大变 => spread 是 E 漂移（口径问题）。
  - §D: 若 coal+scalar 的税随 U 收回 => 税认「每 SM 在飞 load 量 Wsm·U」；若不动 => 只认 warp 数 Wsm。
  - §E: 若同 Wsm·U 的 (U,Wsm) 组合塌成同一点 => 二者是替代品（对上 §60/§68/§70）。
