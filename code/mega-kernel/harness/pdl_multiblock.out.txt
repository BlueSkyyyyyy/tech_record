# cuda: nvcc release 13.2, V13.2.78
# 结构：producer=[pre 自旋]->写 flag[0]=gen->trigger->[tail 自旋]；
#       consumer=[prologue 自旋]->gridDependencySynchronize->校验 flag（仅 block0/thread0 计数）。
# 有效重叠 = (no-PDL − PDL) / (no-PDL 每轮 ms/cycle)；ms/cycle 由 no-PDL 跨度周期（pre+tail+prologue）标定。
# ideal 重叠 = min(tail, prologue) = 80000 cyc；no-PDL 单对 = pre+tail+prologue = 240000 cyc
#   ≈ 240000/1980MHz = 0.121 ms（低 Gu 实测 0.125 ms 与之相符，证明无外部干扰）。
# blocks/SM 与占用上限由 cudaOccupancyMaxActiveBlocksPerMultiprocessor 查询。
# correctness：所有配置 fail=0（每轮 consumer 都读到 producer 的当前 gen）。

# 读法：
# Section A：Gd=1 时，上游 Gu 远低于 cap 时有效重叠 ≈ 理想 min(tail,prologue)（~1.00×）；
#   Gu 逼近 cap（上游占满 occupancy）时有效重叠明显缩水——收益被「上游占用率」吃掉。
#   两种 blockDim 下都收敛到 ~0.74×ideal（B=256 @Gu=1056=cap；B=128 @Gu=1584=0.75cap）。
# Section B：Gu 固定、下游 Gd 从 1 扫到空闲槽位数，重叠几乎不变：
#   只要 总占用 (Gu+Gd) ≤ cap，下游 grid 多大都不影响重叠。约束在「上游给不给余量」。
# Section C：上游占满 cap 时，重叠不随 prologue 无限增长，而是饱和在一个天花板（~0.74×ideal）；
#   prologue=0 时重叠 ~0（无 prologue 可提前做，与 P4-2 一致）。
# 含义：PDL 帮助的是「上游没有占满 SM」的情形；生产 megakernel 恰恰相反——它用一个常驻
#   kernel 占满全部 SM（见 docs/04 §5、MPK §5.1），所以在单 kernel 内用去中心化 event queue
#   做 task 级重叠，而不是靠 PDL 跨 kernel 挤 SM 槽位。
