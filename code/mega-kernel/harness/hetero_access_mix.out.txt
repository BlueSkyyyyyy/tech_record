===== §F 结论 =====
  - §C meas/exp > 1 => 混合**优于**时间切片（共驻互补）；< 1 => 共驻**干扰**（抢 HBM）。
  - §D 异质性税 = 混合最佳单一 (T,O) / oracle(各模式各自最优)。<1 即『一套参数通吃』的代价。
  - §E physGB/s(≈4× 稀疏流量) 应逼近 HBM 天花板 => 逻辑塌是**物理流量墙**、非额外干扰。
