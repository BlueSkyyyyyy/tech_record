>> 读法：
>>  §A：固定 carveout，hitRatio f 越小 → 去挤 carveout 的访问越少 → 保护量应≈f×S；
>>      若 f<1 时 K2 仍快，说明「概率化分区」能少占 carveout 而近似保护。
>>  §B：pfull（carveout=31MB）的 ~1.5× 代价，能否用「更小 carveout + hitRatio<1」收回。
>>  §C：两个并发中间量共享一个 carveout —— 拆分 DRAM 读用 `one2` 的 ncu 采样。
