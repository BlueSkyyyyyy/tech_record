===== §F 结论 =====
  - §C: bind_opt 若明显 > bind_bal => §73 的分区自伤主要是**常数速率模型**造成的，
        按实测曲线配平可收回；bind_opt 的 coal+scalar 若仍 ~0.90 => 全局发射税分区补不回。
  - §D: bind_opt 应在 sparse/l2res 上少给 SM（其速率低 SM 数即饱和），把 SM 让给 coal/scalar。
