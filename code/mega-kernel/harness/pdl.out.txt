checksum (consumer 成功读到 flag 的累计次数，末轮值): 501

>> 读法：no-PDL 时下游严格等上游整段跑完，total≈pre+tail+prologue；
>> PDL 时下游 prologue 与上游 tail 并行，total≈pre+max(tail,prologue)；
>> prologue 越大收益越大（上限 min(tail,prologue) 被省下）；
>> prologue=0 时 speedup≈1——PDL 不是万能加速，只重叠「下游本可提前做的活」。
