>> 读法：
>> A: fused<H> 的 numRegs = max(light, heavy<H>)，即 megakernel 的 per-thread 寄存器
>>    被固定为各 task 最大值（MPK §7 行 1748）；occupancy 随最重 task 下降。
>> B: 同样的轻访存工作，只要 kernel 里编进了重 task，轻 task 的带宽就下降 —— 隔离出
>>    寄存器足迹这一项的代价（占用率低 -> 驻留 warp 少 -> 藏不住 HBM 延迟）。
>> C: 时分复用（每 block 轻后重）下单 kernel vs 两次 launch：单 kernel 的轻阶段被重 task
>>    的寄存器拖累，而两次 launch 让 light 按自己的高占用率跑。差值即 megakernel 此项代价。
>> D: SMEM 足迹同样会压占用率（若按各 task 最大值常驻）；MPK 用 paged SMEM(§5.3 行 1313-1325)
>>    按 task 粒度申请/释放来规避，**唯独寄存器不能规避**（§7 行 1748）。
