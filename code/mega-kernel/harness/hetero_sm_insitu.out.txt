===== §G 结论 =====
  - §C: bind_insitu 若把 coal+sparse 从 bind_opt 的 0.664 抬回 >1.0 => §74 的崩盘是**单跑曲线**
        的错、in-situ 测量可收回；coal+scalar 若仍 ~0.95 => 全局发射税依旧不可分区解。
  - §D: in-situ 曲线里 sparse 的分区速率应在小 n 即压平（单跑曲线看不出，故贪心狂喂 sparse）。
  - §F: 爬山轨迹应显示 in-situ 把大量 SM 从 sparse 挪给 coal，收敛到 n_sparse~32 附近。
