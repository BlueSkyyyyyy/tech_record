# P29-1 小实验原始输出：Thread Block Clusters + DSM（跨 SM 中间量交换原语）
# date: 2026-10-13
# cmd: bash code/mega-kernel/harness/cluster_dsm.sh   （经 scripts/lab.sh exec 在 kernel_lab 容器内）
#      -> nvcc -O3 -arch=sm_90 src/cluster_dsm.cu -o /tmp/cluster_dsm；每个配置单独进程
# gpu: H100 80GB HBM3 x8, sm90, SMs=132（固定在空闲 device 1；每配置独立进程，因 cluster
#      launch failure 会污染 CUDA context）
# cuda: nvcc release 13.2, V13.2.78
# 说明：
#  A : cluster 内读「环形邻居」的 SMEM（C=1 退化为读自己 SMEM = 本地基线）；grid=128, 16KB/block,
#      R=20000，每次一个 volatile load/线程/轮（变界 stride 循环会触发编译器问题，见文档 §18.6）。
#  Lg: plain 全局流式读 256 MB（>50MB L2）作 HBM 参照。
#  S : ring 段位移，双缓冲 ping-pong、1 次 cluster.sync/轮；段放 global scratch(hbm) 或自己 SMEM(dsm)。
#      每轮读邻居整段 + 写自己整段（seg=K*256 float）；maxerr=0 表示与解析参考逐位一致。
#  C1/C3: cluster.sync() vs grid.sync() 成本（R=200）。C2: cluster 容量/合法性。
