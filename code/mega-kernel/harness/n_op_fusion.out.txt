>> 读法：
>>  流量模型：eagerN/graphN/persistN = 8N B/元素（中间量落 HBM）；fusedN = 8 B/元素。
>>  e/persist 度量「消掉 N-1 次 launch/grid 启动」（损失二，设备侧）。
>>  e/fused 度量损失二 + 「中间量不落 HBM」（损失三）之和。
>>  Section B 带宽主导：e/fused 应随 N 线性增长（趋近 N×）。
>>  Section C launch 主导：小 M + 大 N 下 eagerN 的 N 次 launch 显形。
