>> 读法：
>>  e/g  : graph 相对 eager 的收益（只消 host 侧提交，设备侧仍 2 次 grid 启动）。
>>  b/e  : barrier 相对 eager（单 launch + kernel 内 grid barrier，仍走 HBM 中间量）
>>          → 这一档度量「消掉第 2 次 launch/grid 启动」的收益（损失二）。
>>  f/b  : fused 相对 barrier（同样单 launch，但中间量不落 HBM）
>>          → 这一档度量「消掉中间张量 HBM 往返」的收益（损失三）。
>>  本实验带宽主导，故 f/b 应接近 2×（16 B/elem vs 8 B/elem）。
