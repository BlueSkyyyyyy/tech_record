## 一、Agent：从「会调工具」到「会省钱地用上下文」

### 1. From Autonomous Agents to Cognitive Symbionts（119↑）

Toward AI-Augmented Human Intelligence · University of Oxford · [2611.05376](https://huggingface.co/papers/2611.05376) · [项目页](https://cognitive-symbiont.github.io/)

- 这是一篇**立场论文**，不是系统论文：作者认为 Physical AI 只有「具身机器人」一半，另一半是「被 AI 增强的人」，并把它命名为 **AHI**（AI-augmented human intelligence）——不问机器能多聪明，而问机器能让某个具体的人多聪明。
- 核心概念是 **cognitive gap**：一个人「本可以带进某个情境的能力」与「工作记忆里实际装得下的东西」之间的差。围绕它把设计空间摊成一个**共生环**：sensing（借外部设备感知）→ keeping（跨年保留上下文）→ understanding（建模情境与心智）→ living alongside → acting for / thinking with → growing，外面套一层 personal runtime 与 trust。
- 对做系统工程的人有两处硬约束值得抄：**lifelong、real-time、private、low-friction、proactive** 五条要同时成立；以及它把治理写进范式本身（考场里的隐蔽辅助、不采用者的竞争压力）。
- 我的看法：框架清晰，但没有任何量化验证，适合当「需求文档」读，不适合当技术方案。

### 2. VFlash: Fast, Accurate Visual Planning（107↑）

Via Flash Primitive Decoding · NVIDIA · [2611.08449](https://huggingface.co/papers/2611.08449) · [项目页](https://research.nvidia.com/labs/lpr/vflash/)

- 问题：VLA / 自动驾驶模型用**视觉 plan**（点、bbox、轨迹）表达空间目标，但自回归 VLM 一个 token 出一个坐标，图元越长越贵。
- 方法：利用图元的已知结构做**联合预测**——一个轻量 drafter 一次前向吐出整个图元，layout 随图元类型 / 维度 / 长度自适应（短 bbox 与长变长轨迹都能装）。
- 关键取舍：**不要求复现自回归模型的 token 序列**，只要求预测「结构上合法」；训练用标注图元直接监督。像 speculative decoding，但接受判据换成了几何合法性。
- 数字：2D/3D 机器人轨迹任务上预测误差一致低于自回归解码；3D 点运动预测单次 rollout 约 **25×** 加速；以 VFlash plan 为条件的 world-action model 在 MolmoSpaces 四个任务套件上平均成功率 **70.2% vs 62.6%**（baseline）。

### 3. Harness-S: Learning from Sibling Harnesses（66↑）

For Generalizable Agent Training · 上海交通大学 · [2611.04277](https://huggingface.co/papers/2611.04277) · [code](https://github.com/DeepExperience/Harness-S)

- 出发点是一个很工程的观察：从同一个 base 演化出的 harness 变体，表现出 **Locality / Complementarity / Nonstationarity** 三个性质（各修各的 bug、修的地方不重叠、价值随策略变化），所以不存在「普遍更好的 harness」。
- 做法三步：**Directional Harness Evolution** 沿不同修复方向造专门的 sibling harness，组成训练期固定的 Sibling Harness Pool；**Complementary Harness Rescue Training** 只在 base harness 下整组 rollout 全失败时，用辅助 harness 重采样并把轨迹替换进 RL 组；**Adaptive Harness Router** 按 Harness Behavior Profiles + 多个 LLM 投票选 Top-k，并随策略更新重新锚定。
- 结果：AppWorld / SWE-Gym / DBBench 上，**回到原 base harness 推理**时明显强于 policy-only 训练，说明能力被搬进了策略本身而不是留在 harness 里；同一 router 用于 Rank-1 推理还能在相同 rollout 数下再涨一点。
- 对 agentic RL 的启发：harness 是**数据分布的一部分**，与其调一个万能 harness，不如把「失败样本的分布」当成可换的采样器。

### 4. EvoMemState: Evolving Memory State（33↑）

For Personal Agents · 厦门大学 · [2611.03743](https://huggingface.co/papers/2611.03743) · [code](https://github.com/XMUDeepLIT/EvoMemState)

- 现有长期记忆系统基本都是**事实中心**（抽取 → 组织 → 更新 → 检索），弱点在于：新事实如何约束 / 冲突旧事实、某条事实在当前请求里该不该用、优先级如何，全都不显式。
- EvoMemState 加两层状态：**Relational States**（事实之间如何仍然有效、作用域、演化关系）+ **Reasoning State**（这次请求该怎么用这些事实）。三组件：本体引导的状态归纳、**RL 训练的状态演化**（把「用记忆的经验」内化进策略）、状态感知推理。
- 结果：长期对话与 memory-use 基准上，检索完整性与 memory-grounded 回答准确率一致优于现有记忆系统。
- 值得注意：它把「记忆」从检索问题改成了**状态机 + 策略问题**，和 agent context engineering 是同一个方向。

### 5. Drex: Towards Foundation Decision Models（22↑）

Nace.AI · [2611.07854](https://huggingface.co/papers/2611.07854) · [code](https://github.com/nace-ai/drex-decision-models)

- 论点很直接：生产环境里自回归 + 长 CoT 的问题是**答案不稳、要解析输出、贵且慢**。决策模型给定「一个 state（文档 / 记录 / agent context，可带图）+ 若干问题（选项选择 / 是否判断 / 有序打分）」，**不做自回归解码**，直接返回选项上的概率分布。
- 四个开源模型：8B（DLM）、9B（v1.5）、35B-A3B（v2.0）、27B（Max）。训练 = SFT + **RLAF**（from adjusted feedback 的 RL），Max 另做视觉微调；消融显示 RLAF 提准确率，**一致性 loss 提升选项顺序鲁棒性**。
- 数字：Decision Index 0.4.1 公开集 **67.52 vs 60.70**（Jev 1.14.0）；Decision Bench v4 与 d3-turbo、GPT-6 Sol 统计打平，落后 Claude Opus 5.5 **1.6 分**；典型请求 **183 ms**（GPT-6 Sol ≈2.0 s，Claude Opus 5.5 ≈3.5 s）。
- 这是把「分类 / 打分 / 选择」从生成式里摘出来的路线：延迟差一个数量级，代价是**只能回答你给好的选项**。

## 二、具身：把空间与记忆做进基础模型

### 6. Speculative Listening（8↑）

Decode Before You Hear: Chunk-Interleaved Full-Duplex Speech LMs · 香港中文大学（深圳） · [2611.06982](https://huggingface.co/papers/2611.06982)

- 全双工语音模型按固定时间块「边说边听」，工作量不对称：listen 块在等音频时算力闲着，speak 与 tool-call 块必须串行生成，拖慢响应。
- 两个实测性质支撑方案：下一块音频**不改变**输出的比例是 **95.3%**；发生改变时 **88%** 从第一个输出 token 就开始。
- 于是做**输入侧自推测解码**：空闲时以「静音」为假设草拟下一块，对首 token 变化再开第二条分支（从 runner-up 首 token 起），草稿进 cross-chunk hypothesis pool，音频到了再校验——**training-free 且无损**。
- 数字：TickTock-Bench 八任务上 speak 块 **2.6–2.8×**、tool-call 块最高 **23.4×**；开始响应前的解码延迟降 **73%** 到 **74–241 ms**（接近人类轮次间隔的 200 ms），最大落后实时量降 **94.4%**。
- 当天我最喜欢的一篇：把推测解码的粒度从 token 换成**时间块**，假设源从 draft model 换成「静音」。

### 7. Coca-Cola: Tools Need Not Speak in Text（6↑）

Latent Context Compression for Agents · 清华大学 · [2611.06500](https://huggingface.co/papers/2611.06500) · [code](https://github.com/THU-Agent/Coca-cola)

- 现状：agent 把**原始工具输出**直接拼进上下文，多步之后又长又噪，既贵又稀释注意力；token 剪枝 / 摘要受限于离散文本，压缩比上不去。
- 做法：把工具观测压成 **latent token**，直接嵌进 agent 的 input embedding 空间；配 **Action-Preserving Training**——对齐「全观测」与「压缩观测」下**下一步动作分布**，逼压缩器只留决策必需信息。
- 数字：网页搜索 agent、4 个 QA 基准、2 个模型家族上，token 消耗降 **70.01%–89.24%**，端到端耗时降 **24.45%–55.97%**，任务表现还一致变好。
- 与 PACT / 潜空间通信同族：**能不用文本就不用文本**，但监督信号是「动作不变」而不是「能重构」——这点值得学。

### 8. DPDM: Decoupled Predictive Decision Making（5↑）

A Shared Conditional Predictor for Agents · Stable AI · [2611.02075](https://huggingface.co/papers/2611.02075)

- 观察：agent 的很多决策依赖**部署观测里才有的经验关系**，任务描述本身给不出。DPDM 因此把决策拆成两半：LM 提供当前 / 历史记录的语义表示，一个**通用条件预测器**从这些表示里预测任务定义的目标。
- 关键约束：**两侧神经参数都不更新**，部署证据只实例化具体预测。工具判断、候选偏好、推理步骤评估共用一套「证据 + 查询」接口，预测再由决策规则映射成选择。
- 数字：Qwen3.5-27B 做语义编码器 + 单个冻结的 LimiX-2 预测器，50 个基准平均准确率 **78.80%（few-shot）→ 84.92%**（各自历史预算下）/ **82.33%**（相同历史与查询）；ToolPRMBench 的 BFCL 与 ToolSandbox 上绝对提升 **34.26% / 28.87%**；五个推理步骤评估任务上平衡准确率绝对提升 **14.51%**；历史越长越准。
- 它的赌注是「从经验中学习」应当成为**可独立改进的基础模型能力**，而不是塞进 prompt 或权重里。

### 9. SwarmEvolve: Latent Agent Swarms（9↑）

For Evolutionary Discovery and Optimization · Brown University · [2611.08483](https://huggingface.co/papers/2611.08483) · [code](https://github.com/Qile-J/SwarmEvolve)

- LLM 引导的进化搜索（AlphaEvolve 一类）慢在两点：每轮要生成很长的文本 CoT，且要重复很多次来维持种群多样性。
- SwarmEvolve 让**每轮数百个低成本 agent** 组成 swarm，**在潜空间里推理、不解码成文本**，靠**传 KV cache** 共享信息；每个 swarm 从不同角度看问题。
- 两个有意思的设计：**novelty filter** 直接量 hidden state 向量距离筛掉重复想法；**crossover 在潜空间自然发生**——summarizer agent 直接接收全体成员拼接后的 KV cache。
- 数字：21 个数学发现 / 科学计算问题上平均分最高，达到其他 SOTA 框架 60 分钟成绩的中位数只需 **3–8 分钟**；若干问题上 **Qwen3 8B** 就超过了 AlphaEvolve 用前沿模型首轮找到的解。
- 注意算力账：数百 agent × 每轮，省的是**解码时间**，不是 FLOPs。

### 10. SLA: Scaling Spatial-Language-Action Model（93↑）

Via Continual Pre-training · 香港科技大学（广州） · [2611.08373](https://huggingface.co/papers/2611.08373) · [项目页](https://embodiedsla.github.io/)

- 问题定位很准：VLA 的视觉表征继承自 **2D** 视觉-语言预训练，空间监督通常只在任务适配阶段才引入，于是「空间理解」永远不会成为可迁移的基础能力。
- 做法：从 **π0.5** 策略初始化，持续预训练时同时优化动作预测与**中间层视觉 embedding 对齐冻结 3D 感知模型的空间表征**；为此统一了异构机器人数据集，并用 **feature-dependent gates** 自适应聚合多个 VLA 层的视觉 embedding 供监督。
- 工程细节两点：teacher 能利用**部分可得的深度与相机标定**（不要求全都有几何标注）；**probabilistic state dropout** 逼模型依赖视觉而不是记住示范轨迹。
- 最实用的性质：所有辅助组件**只在训练用**，推理架构与权重完全照旧——不需要改部署。

### 11. Open-HumanScale: 50K Hours（33↑）

An Open Recipe for Scaling Human and Robot Experience · 北京大学 · [2611.06817](https://huggingface.co/papers/2611.06817) · [项目页](https://dagroup-pku.github.io/open-humanwam/)

- 产出是一个**全开放配方**：Open-HumanScale-50K，5 万小时第一人称视频，带稠密手部运动与自然语言标注，外加数据整理与预训练流水线、预训练 / 后训练 checkpoint、推理代码与仿真评测套件。
- 最有价值的是一条**经验对数线性 scaling law**：纯人类视频预训练的小时数与下游机器人成功率呈 log-linear（在闭环仿真里系统测量）。
- HumanWAM-Vanilla（纯 5 万小时人类视频预训练的世界-动作模型）后训练后：RoboTwin 2.0 **92.08%**（Clean2Clean）/ **68.88%**（Clean2Random），RoboDojo 平均成功率 **14.17%**、平均进度 **19.00**。
- 再往前一步的 HumanWAM-Goal（视觉目标条件化）做人机联合预训练：Clean2Clean **92.70%**、Clean2Random 跳到 **84.60%**；真机上出现**无需更新参数**的 embodied in-context learning。68.88 → 84.60 是当天最陡的一条曲线。

### 12. VisSearch-Bench: Long Horizon Visual Search（22↑）

Ant Group · [2611.04894](https://huggingface.co/papers/2611.04894) · [code](https://github.com/antins-labs/VisSearch-Bench-v1) · [项目页](https://dingwu1021.github.io/VisSearch-Bench/)

- 现有搜索基准里图片大多只用来**识别初始实体**，之后全靠文本检索，测不出「跨图像、物体、搜索步连接信息」的能力。
- VisSearch-Bench 收 **204** 个人写任务、7 大领域 25 子领域，五类形态：集合式视觉搜索、序列式视觉搜索、混合宽深搜索、竞争性视觉消歧、视觉结构引导搜索；每题给参考答案、可溯源证据与评分规则，指标分 **Accuracy**（整题成功）与 **Process Score**（子结果 / 子问题对且全）。
- 结果很刺眼：16 个多模态模型里**最强系统带搜索工具也只完整解出 26.47%**。

### 13. DreamFree: Future Representation Distillation（10↑）

For Imagination-free World Action Models · KAIST AI · [2611.04527](https://huggingface.co/papers/2611.04527) · [项目页](https://harryjo97.github.io/dreamfree/)

- 世界-动作模型通常要先「想象」未来帧再出动作，推理贵。DreamFree 把预训练**视频扩散模型改造成预测性视觉编码器**（表征蒸馏），省掉显式想象，同时保留其时空先验，服务实时机器人动作。
- 值得记的点：它蒸馏的不是输出像素，而是**中间表征**——「用生成模型当 backbone」的常见省算法。

### 14. HeLM: Hierarchical Explicit Language Memory（8↑）

For Non-Markovian Manipulation · 首尔大学 · [2611.02660](https://huggingface.co/papers/2611.02660) · [项目页](https://kimspacehuni.github.io/HeLM/)

- 问题：多数 VLA 是**马尔可夫**的（当前观测 → 动作），需要工作记忆的任务直接失败。
- 做法：借「内心独白」，用**显式语言**维护任务相关历史——事件检测做因子化，**事件触发**才更新记忆，而不是每帧都写。
- 数字：10 个非马尔可夫真机任务、56 个变体（含 5 个新定义的跨 episode 任务）；帧内成功率比最强 baseline **+12.8 个百分点**，组合泛化子任务成功率 **78%**；长程下显存最多省 **4.5×**、速度 **2.5×**（对 keyframe baseline）。
- 和 EvoMemState 对照看：一个是语言记忆 + 事件触发，一个是关系状态 + RL 策略，都在回答「历史该怎么存」。

## 三、图像生成与编辑：统一、少步、抗漂移

### 15. WeLM-Image: Unified Image Generation（44↑）

微信 · [2611.07392](https://huggingface.co/papers/2611.07392)

- 定位是**单卡可部署**的统一图像基础模型，覆盖文生图、指令编辑、多参考合成；把文本、参考图、目标 latent 拼成**一条交错序列**。
- 结构：**Mixture-of-Transformers**（共享 attention + 理解 / 生成各自独立参数，减少优化干扰），两条路径都挂 **MoE**；**31.7B 存储参数，每个目标 latent token 激活约 5.4B 生成参数**。
- 训练侧值得抄的是数据引擎：知识驱动的视觉词表 + 大规模视觉聚类平衡语义覆盖与编辑任务，训练中评测反过来迭代数据；生成与编辑**分开用 rubric / checklist 奖励优化**，再用 **noise-aware on-policy distillation** 合并成一个策略。
- 数字：1536 分辨率版本在 PRISM-Bench、Qwen-Image-Bench、UnicBench 上排名开源第一；MeanFlow 少步蒸馏出的 WeLM-Image-Turbo 在**单张 H20** 上 8 步无 CFG 生成 1024×1024 用 **4.98 s**。

### 16. TailSteer: Multi-turn Editing（40↑）

Trajectory-Tail Steering for Drift-Resistant Multi-turn Image Editing · MMLab-CUHK · [2611.06741](https://huggingface.co/papers/2611.06741) · [code](https://github.com/Lyricccco/tailsteer) · [项目页](https://lyricccco.github.io/tailsteer/)

- 现象：单轮编辑强 ≠ 多轮可靠。编辑结果被反复复用，**小的非预期改动会累积成严重视觉漂移**。
- 现有解法各有代价：多轮数据 / 跨轮 rollout 训练会改动预训练先验，推理期专用机制又难扩展到基础模型。
- TailSteer 的原则一句话：**让早期去噪动态贴近 base 模型，把「保真修正」集中在轨迹尾部**（那里细粒度偏差最容易被压住）。修正从编辑器自己的 on-policy 去噪 rollout 里学，用**未改动的源内容**当保真参照，不需要人工编辑对。
- 数字：FLUX / SenseNova / Qwen 三个家族上，15–20 轮编辑的累积漂移大幅下降，同时文生图与单图编辑基准基本不掉。
- 「**在最后阶段打补丁**」范式的一个漂亮例子：不改能力，只改长程稳定性。

### 17. StepX-OPD: Multi-Teacher On-Policy Distillation（4↑）

Rethinking Multi-Teacher On-Policy Distillation in Diffusion Models · StepFun · [2611.04386](https://huggingface.co/papers/2611.04386) · [code](https://github.com/WinterCCC/StepX-OPD) · [项目页](https://winterccc.github.io/Step-OPD/)

- 现状是两段式：先用多教师 on-policy 蒸馏把能力合并进全步模型，再把它当固定 teacher 做少步蒸馏。作者报告**每个全步模型压缩后分数都下降**，且第二段必须等第一段结束。
- StepX-OPD 把两段合成一段：一个 student 在学少步采样的同时学全部能力，**冻结的专家在 student 自己 rollout 到的状态上监督它**（而不是它永远不会跑的长轨迹）。
- 两个发现：对 rollout KL 做分解后，**velocity mismatch 集中在干净端**，所以额外在低噪声段回归 student 的 velocity；能力合流会让模型在「没要求写字」的 prompt 上**往图里写提示词**，作者给了个降低该现象的变体。
- 数字：SD3.5-Medium 与 FLUX.1-dev 上，四步方法里归一化平均分最高，且超过 40 步的 Flow-OPD；SD3.5-Medium 上训练 GPU-hours 比「DiffusionOPD → 少步蒸馏」顺序做少约 **37%**。

### 18. EDGAR: Gaussian Avatar Refinement（16↑）

Efficient Diffusion-Driven Gaussian Avatar Refinement via Synthetic Failure · KAIST · [2611.07909](https://huggingface.co/papers/2611.07909) · [项目页](https://kwanyun.github.io/edgar/)

- 目标：单目视频 / 单图重建的高斯人头 avatar 有欠约束区域，出现模糊、拉伸、时序抖动。
- 做法：条件扩散做**伪影修正**而不损身份——用自监督 Sapiens 模型抽身份特征，注入**一步扩散** backbone 的 fusion block；**MoE** 应对不同退化类型与强度。训练集 EDGAR-SET 是「真实采集 + 合成渲染」的混合三元组，刻意配对退化渲染 / 真值 / 参考图来模拟失败样本。
- 很实用的收尾：修正后的多视角渲染只当**伪目标**去优化**一个**底层高斯 avatar，所以最终渲染不需要每帧都跑 EDGAR。
- 结果：三种重建方法 × 三种设置下感知与重建指标都优于原始输出与 SDEdit 式修正；跨视角校准一致性更好，大偏航角与张口表情下稳健。

### 19. SynthFaces: Balanced Large Scale Human Dataset（1↑）

[2610.40119](https://huggingface.co/papers/2610.40119) · [code](https://github.com/ControlGenAI/SynthFaces)

- 动机：真实人脸数据集**身份分布有偏 + 隐私风险**，训练出的生成模型在身份保持上不公平。
- 做法：在 Arc2Face 基础上，用**身份 embedding 流形上的 flow matching** 可控扩样，兼顾保真与标签多样性；产出以身份为中心的平衡合成数据集，并用最近邻 non-leakage 指标实证身份可分。
- 用途：给公平性研究 / 个性化生成适配器做微调数据。规模与下游收益摘要里没给，得看正文。

## 四、LLM 结构与可解释性

### 20. Muir: Linear Attention with Sensitivity-Allocated Gating（12↑）

And Matched-Filter Readout · Google · [2611.08376](https://huggingface.co/papers/2611.08376)

- 起点是对 Gated DeltaNet-2（GDN-2）的一个**敏感性分析**：状态更新对 **erase 远不如对 write 敏感**——key 激活与 unit normalization 把 key 能量集中到稀疏通道，而 value write 缩放所有通道，所以 erase gate 可以低秩参数化。
- 第二个观察：**慢衰减的状态行范数远大于快行**，在无加权读出里占主导，反过来逼模型用更强的写时擦除来压干扰。
- 于是 Muir 做三件事：把所有 gate 融进一个**敏感性分配的低秩投影**；用 **matched-filter 读出 gate** 重加权状态行；把省下的参数投进**更宽的 FFN**。
- 数值稳定性：要跑满宽矩阵单元需要很大 chunk，标准 chunkwise 算法在那里不稳，作者设计了**并行更新**。
- 数字（166M–1.34B）：困惑度比 GDN-2 低 **1.8–2.0%**、比 Transformer 低 **2.5–3.6%**；常识准确率最高 **+1.9 分**；抽取式召回优于 GDN-2；1.34B 上多跳 / 多针召回双赢，**从 4K 训练长度外推到 10M token 流困惑度不漂**，静态读出下 **100 万 token passkey 近 100%**；吞吐持平 GDN-2、达到其 100B token 验证 loss 快 **1.2×**，32K 下训练比 Transformer 快 **2.7×**。
- 对做 kernel 的人：**低秩 erase + 加权读出**直接改变 chunkwise 实现的状态形状与访存模式，是能落到算子上的结构改动。

### 21. SAE Interprets MoE（8↑）

Sparse AutoEncoders Reveal That MoE Experts Exhibit Human-Interpretable Fine-Grained Specialization · ByteDance Seed · [2611.08089](https://huggingface.co/papers/2611.08089) · [code](https://github.com/ByteDance-Seed/SAE-interprets-MoE) · [项目页](https://bytedance-seed.github.io/SAE-interprets-MoE/)

- 批评现有做法：按领域标注语料统计「专家被选中频率」，等于**先固定分类法**、粒度粗、且记录的是 selection 而不是 contribution。
- 方法很干净：在 MoE 层**输出**上训 SAE。由于该输出是各专家输出的 router 加权和、且 SAE encoder 是仿射的，**每个 latent 的 pre-activation 可以精确分解到各专家**；语料上聚合就得到每个专家的 dominant latent 集合。
- 发现（Qwen3-30B-A3B 第 4 / 30 / 46 层）：**贡献比 gating 集中得多**，多数 latent 只有 1–2 个 dominator，dominant 集合的重叠集中在少数专家对上。
- 自动解释显示分工细到「Java vs 前端 web 代码」「几何 vs 算术与多项式」这种**粗领域之下**的层级，而粗领域本身占用的专家数极不均衡。

### 22. PACT / PLatour: Cross-Model Transfer（15↑）

On the Opportunities and Challenges of Prefill-to-Autoregressive Cross-Model Transfer · King's College London · [2611.06976](https://huggingface.co/papers/2611.06976) · [code](https://github.com/zhenyi4/platour)

- PACT 的思路：大模型做 prefill、小模型做自回归生成，中间用**潜空间通信**传信息，兼顾能力与成本。
- PLatour 是开源框架：冻结的两个模型之间接**零初始化线性 bridge**，直接用任务奖励训练，支持 hybrid-attention 架构；生成任务上明显超过开源 baseline，数学 / 代码基准上用**小得多的 sender** 超过 Mostik 报告的结果。
- **但这篇真正的贡献是泼冷水**：受控实验表明，部分任务上的增益可以靠**无信息的 sender 信号、自己跟自己通信、只训 receiver** 复现——可训练 bridge 完全可以只当参数高效适配器，而不真的利用 sender 信息。
- 作者因此提出 **PACT-Check**，用来量化「一个训好的 PACT 系统，增益里有多少真的来自通信」。
- 当天方法论上最值得记住的一篇：跨模型 / 多 agent 通信类工作，**没有 PACT-Check 级别的对照，涨点不算数**。

## 五、评测：可靠性本身成了研究对象

### 23. BestRand: Benchmark Compression（51↑）

Random Is Almost Enough? Stable and Low-Cost Benchmark Compression via BestRand · CMU · [2611.00883](https://huggingface.co/papers/2611.00883) · [code](https://github.com/George-Ling3/BestRand)

- 理论部分：推导了「用子集估计全基准分数」时误差分布的解析近似，结论是**大多数子集误差很小、少数子集误差极大**，整体呈长尾。
- 推论一：纯随机采样在高概率下已经很强——「Random is almost enough」。
- 推论二（更重要）：这种不稳定是**现代基础模型固有的**，评测更多模型也不会消失。
- BestRand 在保留随机采样效率的同时压掉高误差尾部：70+ 文本 / 多模态 / agent 基准（并扩到 VLA）上，相比竞争方法高误差风险降 **50.2%**、估计误差平均降 **16.4%**，构建成本只要 **51.3%**；OOD 估计误差在分数区间、模型家族、时间漂移三类 shift 上平均降 **21.8%**。

### 24. TB-MathModel: Terminal-style Mathematical Modeling Bench（11↑）

The First Agentic and Verifiable Benchmark for Mathematical Modeling · IDEA FinAI · [2611.08237](https://huggingface.co/papers/2611.08237) · [code](https://github.com/wxj630/terminal-bench-math-modeling) · [项目页](https://wxj630.github.io/terminal-bench-math-modeling/)

- 把完整赛题式数学建模做成**终端里的 agentic 任务**并**可验证**：不止评最终数值，也评过程；适合测「长程 + 可执行环境 + 自动判分」这一类 agent 能力。

### 25. OpenFrontiers: Scientific Rediscovery（6↑）

[2610.37739](https://huggingface.co/papers/2610.37739) · [项目页](https://openfrontiers.vercel.app/)

- 资源：**12,151** 个开放研究问题的结构化语料（含问题陈述、背景、进展）+ 一个**回顾性基准**：200 个近期已解决的问题（110 个 2026 年已解、90 个仍开放），每题带 **Lean 4** 陈述，经自动探针与两位独立评审检查；**HQ-50** 再按质量筛。

### 26. NPCBench: Clinical Care-Pathway Reasoning（3↑）

A Clinical Apprenticeship Benchmark for Multimodal Care-Pathway Reasoning in Nasopharyngeal Carcinoma · InfiX.ai · [2611.08369](https://huggingface.co/papers/2611.08369)

- 现有医学基准把能力拆成孤立事实题、单图题、静态病例，测不出「能否把亚专业知识与多模态证据整合起来、并跟踪病人整个诊疗过程」。

## 六、表示、安全与感知

### 27. Trainable Prefix Tokens for Retrieval Embeddings（6↑）

Reducing Representational Interference in Retrieval Embeddings · 高丽大学 NLP&AI · [2611.07298](https://huggingface.co/papers/2611.07298)

- 问题：embedding 把变长文本压成定长向量时，语义会与**残余 token 级信息**（如 attention sink 造成的伪迹）纠缠。
- 方法极简：训练时在输入前**加可训练 `[DUMP]` token**，架构、pooling、loss 全不动，只走标准对比检索目标优化这些 token。分析显示它改变了低信息 token 的激活与注意力模式。
- 结果：标准检索与长上下文基准上，encoder / decoder 两类 embedding 模型都比微调 baseline 稳定更好。**零结构改动**这条对线上系统很友好。

### 28. Signed but Steerable（4↑）

Measuring and Closing the Text-Vector Integrity Gap in Offline RAG · securagen.ai · [2611.06498](https://huggingface.co/papers/2611.06498) · [code](https://github.com/securagenai/signed-but-steerable)

- 攻击面很具体：端侧离线 RAG 通过**签名知识包**更新，包里带文本和**预先算好的 embedding**。签名只证明「谁发的」，不证明「向量编码了这段文本」。
- 给出 **margin law**：验证器重算向量并按 cosine 容差接受时，被劫持的查询比例等于该容差下**角度检索边界的分布**；五个语料 × 两个 embedding 模型上边界都很小——浮点噪声级容差就暴露最多 **5.5%** 查询（去掉完全重复文档后每个语料 ≤**1.2%**），而按 CPU INT8-FP32 对比校准的阈值（诚实 cosine 的 0.1% 分位）则暴露 **98–100%**。
- 端到端后果：树莓派 5 上跑本地 LLM，这类攻击把正确率从 **0.75 压到 0.39**。压缩索引审计也不行：57,638 文档的 FAISS PQ 索引上，全部通过审计的篡改向量能让攻击者文档在 **25%** 的目标上排第一。
- 修法：**验证量化码**、歧义由验证器裁决、校准 guard band + 规范化——三个平台上诚实向量全部通过，发布方没有选择空间。另附两条结论：常见 FP 与动态 INT8 推理**跨 batch size / 架构不 bit-reproducible**；弃答、上下文剪枝、语义筛三条防线是预注册的**负结果**。
- 对做端侧 RAG / 向量库的人是必读。

### 29. Identically Trained LMs Break on Different Jailbreaks（3↑）

Cerulean Labs · [2610.34074](https://huggingface.co/papers/2610.34074) · [code](https://github.com/cerulean-works/castor)

- 问法很硬：同样的数据、同样的安全后训练，**换一个预训练随机种子**，会栽在同一批 jailbreak 上吗？
- 规模：25 个预训练数据配方 × 3 个种子（1B base）× 相同安全后训练 × 2 个种子 = **150** 个模型；每个模型对同一组 jailbreak prompt 取 20 条回答，两两相关 per-prompt 拒答率。
- 结果：同一次预训练的两个后训练副本相关 **0.984**；**换预训练种子降到 0.811**，再换数据配方只降到 0.779。也就是说「哪些 jailbreak 能破」主要由**预训练那一次跑**决定，而不是数据。全部 25 个配方、150M / 300M 参数上一致。
- 实践后果：在某个 checkpoint 上找到的最优攻击模板（91 个里），换预训练种子后仍最优的模型对只有 **27%**（换后训练种子是 **67%**）。另外每次预训练都留指纹：3,211 个 prompt 上能 100% 认出是 75 次跑里的哪一次，随机 50 个 prompt 也有 98%。

### 30. Real-Time Full-Waveform LiDAR Transformers（5↑）

Via Intensity-Guided Token Reduction and Physics-Aware Augmentation · 庆应义塾 · [2611.07613](https://huggingface.co/papers/2611.07613) · [code](https://github.com/Keio-CSG/FWL-ToPM) · [项目页](https://keio-csg.github.io/FWL-ToPM/)

- 全波形 LiDAR（FWL）保留完整回波直方图，能扛雾 / 雨 / 透明物 / 低反射，但 Transformer 有两个瓶颈：低强度背景区**冗余 token** 太多、标注数据太少。
- FWL-ToPM：按**强度分布**做 token 剪枝与合并；FWLAug：保留每条射线的 ToF 波形与视锥几何的**物理感知增广**当作正则。
- 数字：Ghost-FWL 上实时吞吐下 **8× 以上加速**、F1 比前 SOTA **+近 9 点**，号称首个实时且同时涨点的 FWL Transformer；OOD 未见场景也涨。

## 今天的三个观察

1. 关于「潜空间」：**它正在吃掉「文本交接」的位置**。SwarmEvolve 传 KV cache、Coca-Cola 传 latent token、PACT 传 hidden state——三者都在赌同一件事：文本是 agent 之间最贵、信息损失最大的接口。但 PACT 那篇同时提醒：**这类增益很容易是假的**，必须有「无信息 sender」「自通信」级别的对照。
2. 关于「能力」与「稳定性」：**它们被拆成了两个独立问题**。TailSteer 只在去噪尾部修多轮漂移，BestRand 只压误差长尾，StepX-OPD 只在低噪声段回归 velocity——都不重训能力，只补长程 / 分布尾部。对系统工程的启发是：**先定位失败在轨迹的哪一段**，再决定改哪里。
3. **评测本身在变成研究对象**。BestRand 说压缩子集误差是长尾且不可消除，OpenFrontiers 说联网解题多半是检索，VisSearch-Bench 说最强 agent 只解 26.47%，NPCBench 说单项强 ≠ 路径对。共同结论：**单点分数越来越不可信，过程与条件必须一起报**。
