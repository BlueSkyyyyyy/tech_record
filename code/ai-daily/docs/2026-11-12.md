## 一、数学监督：教科书的结构，比题海更值钱

### 1. TOME-Math（26↑）

Scaling Mathematical Proof Supervision from Structured Textbooks · Intern Large Models · [2610.40394](https://huggingface.co/papers/2610.40394) · [项目页](https://tome-math.github.io/)

- 问题：数学监督通常被压平成孤立的「题—解」对，教材原本的课程编排和证明的证据结构在清洗时全丢了。丢结构换来的是规模，但模型学到的是「这类题大概这么解」，不是「这个结论依赖哪条命题」。
- 数据：TOME-Math（Textbook-Oriented Mathematical Evidence）把 2,118 本覆盖大学数学核心科目的教材转成约 380K 条结构化证明监督记录，保留章节顺序、命题—证明链接、依赖引用和来源出处（provenance）。
- 训练：拿这些结构信号做跨科目的 curriculum learning，并系统刻画随监督量、来源广度变化的 scaling 曲线，而不是只报一个全量结果。
- 数字：全量微调后，在 held-out 评测与既有公开 benchmark 的无加权平均分上比 base model 高 16.7 个百分点，聚合口径上超过论文评测的三个公开 instruction-data baseline。
- 为什么值得看：这是一次「数据组织方式」的消融，不只是「数据量」的消融。对训练系统来说，380K 条带依赖边和来源的记录意味着 dataloader 得支持按章节/依赖采样，随机 shuffle 会把这篇文章最大的卖点洗掉。

### 2. Self-Learning in LLMs via RL（15↑）

Incentivizing Self-Learning in Large Language Models via Reinforcement Learning · Intern Large Models · [2610.39671](https://huggingface.co/papers/2610.39671)

- 问题：参数化知识加 RAG 能答知识密集题，但面对不熟悉的领域，需要的是「现场学会」——自己检索、研读长文档、再把原理用到新题上。检索几个事实、或只在一个预先拼好的 context 里学习，都不够。
- 任务：基于教材的数学解题。模型要在教材讲解里导航，学并应用相关原理，为习题构造证明，且参考答案不给。
- 方法：BookNavigator 接口支撑这种「人类式研读」过程，再用 RL 加细粒度奖励去激励 self-learning，而不是直接监督最终答案。
- 数字：Intern-S2-Preview-35B 的总体 proof accuracy 从 51.5% 提到 79.5%，跨域内/域外教材与科目都有效；在 BrowseComp-Plus 和 CL-bench 上分别比 base 高 1.7 和 2.3 个百分点；优于 textbook-free 的 RL 和固定检索 baseline。
- 为什么值得看：和上一篇同一天、同一机构、作者高度重叠，却走了相反的路：一个把教材离线固化成 380K 条监督，一个让模型在线自己读。RL 版还能把增益带到 long-context benchmark 上，说明学到的是「怎么学」，不只是「教材里有什么」。

## 二、Agent 环境：从洛圣都到厨房，都要自动判定

### 3. GTAGym（10↑）

GTAGym: Real AAA Game Tasks Environment for Evaluation and Reinforcement Learning · OpenMOSS · [2611.13028](https://huggingface.co/papers/2611.13028) · [code](https://github.com/ljbro/GTAGym)

- 问题：AAA 游戏能同时考感知、推理和控制，但任务成败很难自动验证，现有评测大量依赖人工标注，更谈不上拿来做 RL 的 reward。
- 环境：GTAVBench 从 GTA V 主线任务重建 103 个在线任务、覆盖 9 个任务族，另有 47 个基于游戏图像的射击/狙击任务；web server 提供在线环境与评测接口，支持截图 + 键鼠动作的并行测试，结果由引擎状态自动判定。
- 难度分支：GTAVBench-AGI 只在第一张截图里给指令，harness 自动压缩交互历史——考的是「忘了原话之后还能不能把任务做完」。
- 数字：评了 6 个前沿 LLM，最佳配置在 GTAVBench-AGI 上总体准确率 70.9%；空中导航、逃逸和拦截仍是明显短板。生成器支持在固定模板下按参数范围采样，批量造 3D 与图像射击环境；Qwen3.8-27B 在生成的徒步导航任务上做 LoRA RL，原生 GTA V 任务从 15% 提到 23%，并迁移到域外任务类别。
- 为什么值得看：它把「开放世界游戏」做成了带自动 reward 与终止信号的环境，而且以网页服务形态提供并行评测。对 agent 基建来说，这比再刷一个 benchmark 分数有用得多。

### 4. Interactive Visual Gym（0↑）

Evaluating Visual Interaction Models with Simulated Users in Interactive Worlds · Salesforce AI Research · [2611.08286](https://huggingface.co/papers/2611.08286) · [code](https://github.com/SalesforceAIResearch/Interactive-Visual-Gym) · [项目页](https://interactive-visual-gym.salesforceairesearch.com)

- 问题：视觉交互模型是在用户做事的途中给建议，回答会改变用户下一步动作，进而改变任务结果。离线回放的 benchmark 把用户行为固定住，恰好测不到这个闭环。
- 方法：联合模拟「可执行任务环境」和「人类用户」。三个模拟器覆盖烹饪、家务操作、移动界面，动作空间与人类对齐；persona-conditioned 用户模拟器一边配合助手，一边按 persona 制造受控执行错误和计划外行为。
- 规模：实例化为 IVG-Bench，315 个交互场景。
- 数字：最强模型 Gemini 4 Argon 在时限内只完成 53.4% 的任务，事实 grounding 和可执行指导都弱，把响应延迟算进去后常常慢到来不及阻止错误。人类研究显示，交互质量指标与参与者偏好的一致率为 78.5%。在烹饪环境用 GRPO 做闭环训练，Qwen3.5-4B 的任务成功率和交互质量同时提升。
- 为什么值得看：0 票，但它把「人」也建模进环境，并用人类偏好反过来校验自动指标（78.5%）。这类工作的产出不是榜单，而是训练信号——摘要里的 GRPO 实验就是证据。

## 三、推理成本：路由、输入、权重，三层各切一刀

### 5. PISA / PISA-E（6↑）

Ensemble Routing for Prompt-Adaptive Cost-Aware LLM Inference · [2611.10193](https://huggingface.co/papers/2611.10193)

- 问题：Web 服务要在异构请求上平衡质量与成本。常规路由一个 prompt 只选一个模型，固定 ensemble 又没法按请求调整成员与规模，两头都不够细。
- 方法：PISA 用软聚类归属（soft cluster memberships）加每个模型专属的预测器，估计各模型对这个 prompt 的能力；PISA-E 在这组估计上联合选择 ensemble 的组成与基数（cardinality），成本—质量偏好可以在推理时调，不用重训。
- 工程：用一个可计算的 ensemble 成功率代理指标加高效候选筛选，避免为 ensemble 单独训练一个控制器。
- 数字：4 个 LLM 路由 benchmark、ID 与 OOD 两种条件。PISA 的 macro-average cost-performance hypervolume 在单模型路由里两种条件都最高；PISA-E 在质量优先时 macro-average 任务表现比最强对手高 2.09（ID）、2.87（OOD）个百分点；在更低的成本工作点上，任务表现仍超过最强 ensemble，同时平均推理成本降约 36%（ID）和 25%（OOD）。
- 为什么值得看：它把路由从「分类选一个模型」变成「估能力 + 选组合」，而且成本旋钮在推理时可调。对 serving 系统，这是一个不需要重训就能上线调参的调度层。

### 6. SparseRead（4↑）

Read Less, Solve More: Token-Efficient Sparse Reading of External Content for AI Agents · 中科院计算所 · [2608.22237](https://huggingface.co/papers/2608.22237)

- 问题：面向 Web 的 agent 反复读网页、文档、仓库和工具返回，但阅读接口往往整篇暴露，而任务只需要其中稀疏的一点证据。over-reading 既烧 token 和延迟，又会把真正相关的证据稀释掉。
- 方法：SparseRead 是一个可复用的阅读控制层，不改 agent 模型本身。Read Intent Protocol 跟踪不断变化的需求与来源覆盖；Adaptive Reader Backends 决定证据怎么定位、怎么呈现；Budgeted Read Gate 限制每个 episode 累计的原始暴露量，并保留忠实的 full-view 回退路径。
- 接口：统一的 Reader 接口，让异构资源上的证据获取可以互换。
- 数字：6 个模型（含 Claude Opus 5）、5 个场景，总 token 最多降 92.9%，wall time 最多降 89.0%，97% 的设置里任务质量保持或提升；Web deep-search 任务上 token 降 31.0–43.0%、完成时间降 23.0–37.0%；与 3 个 agent 框架集成验证了可移植性。
- 为什么值得看：省的是 context 预算，不是模型能力，因此能和任何模型叠加。它和 PISA 同一天出现，说明成本优化正在从「换更小的模型」转向「控制模型看什么、由谁来看」。

### 7. SteerDistill（0↑）

Quantizing LLM Agents via Closed-Loop Teacher Steering · [2611.13410](https://huggingface.co/papers/2611.13410) · [code](https://github.com/air-embodied-brain/SteerDistill) · [项目页](https://air-embodied-brain.github.io/SteerDistill)

- 问题：低比特量化能降 agent 的推理成本，但会掉任务成功率。作者翻了失败 rollout，发现量化 agent 不是「算错」，而是忽略任务要求或环境条件，产生的环境转移和全精度成功参考对不上。
- 难点：这种 behavioral divergence 不好修——离线数据覆盖不到学生自己的失败上下文，学生自己的 rollout 在这些上下文里又几乎给不出正确响应。
- 方法：SteerDistill，量化感知蒸馏。全精度 teacher 先引导学生改写失败响应，再用学生执行反馈迭代改进指导，形成闭环的「本地已验证」修正；随后让学生在没有指导的情况下训练，在修正轮对齐被指导过的学生、在其他轮对齐全精度 teacher，从而部署时不需要 teacher。
- 数字：5 个 agent benchmark、3 个模型，W4A16 下平均分比最强量化 baseline 高 1.67–2.18 分，与 BF16 的差距在 1 分以内；τ²-Bench 上成功率比 QeRL 高 1.84 个百分点，训练 GPU 时间少 67%，成功轨迹也更短。
- 为什么值得看：量化损失不只在权重误差，还在行为 divergence；在 rollout 层修比在权重层修更直接。67% 的 GPU 时间节省是能直接进部署账的数字。

## 四、评测：协议能改分数，分数不等于认知

### 8. WMIP（2↑）

A Working-Memory-Inspired Programmable Probe of Cumulative State Tracking in LLMs · [2603.27343](https://huggingface.co/papers/2603.27343) · [code](https://github.com/dengzhe-hou/WMIP) · [项目页](https://dengzhe-hou.github.io/WMIP/)

- 问题：人靠工作记忆维持并更新信息；LLM 要在单条 prompt 内跟踪多次状态更新、又不许写出中间状态时，表现如何？现有测试对「能不能写步骤」的约束各不相同，分数没法横比。
- 探针：答案由程序计算，更新次数 3 到 100，查询分最终状态、中间状态、多目标三类，并让不同输出协议跑同一批 item。
- 数字：18 个 LLM，单步算术准确率 84.9%，但「3–7 次更新后只报一个数」的核心 item 只有 31.7%；更新到 50 次以上，没有模型超过 10%。给更大预算、并要求写出步骤且把答案放最后一行，核心准确率到 88.0%，作者归因主要是指令变化而非预算。核心准确率还与 Berkeley Function Calling Leaderboard 分数正相关。
- 为什么值得看：84.9% 与 31.7% 的落差说明单步算术完全不能外推；而同一批题换个输出协议能差出 50 多个百分点。以后任何「状态跟踪」结论，都必须把协议一起报出来。

### 9. CogBattery（2↑）

Human-Referenced Evaluation of Cognitive Task Behavior and Structure in Language Models · [2607.24999](https://huggingface.co/papers/2607.24999) · [code](https://github.com/dengzhe-hou/CogBattery) · [项目页](https://dengzhe-hou.github.io/CogBattery/)

- 问题：模型可以复现人类效应的方向，却犯完全不同的错。只比「哪边更高」，会把这种差别藏起来。
- 方法：54 个 open-weight 模型，跑 13 个认知范式的文本改编版，每个条件都与原始研究的人类数据对齐比较。
- 数字：和人类一样，模型对 n-back lure 的反应强于对照，但对普通非目标的 false alarm 远多于人类；多数模型自报置信度区分对错的能力弱于人类；多数模型永远押同一个 wager，连分类很准的模型也这样。跨任务分数共享两个维度，第一个与 scale 紧密相关，但更大的模型并不稳定更接近人类；预定义的认知分组相对同规模随机分组，没有可靠的预测优势。
- 为什么值得看：这是对「benchmark 分数 = 认知能力」最直接的一次反驳。做 eval 的人该带走的是：报告错误结构，而不只是准确率；按模型规模外推「像人程度」，没有依据。

## 五、训练与权重：优化器的几何，和权重编程的边界

### 10. GraphMuon（1↑）

Module-Aware Optimization for Graph Neural Networks · [2611.08379](https://huggingface.co/papers/2611.08379) · [code](https://github.com/guy-hadad/GraphMuon)

- 问题：Adam/AdamW 做坐标级更新，Muon 利用权重矩阵结构做正交化更新。但 GNN 里权重矩阵的有效几何不只由学到的 channel-mixing 权重决定，还由它作用的 graph-propagated 表示决定——一个作为矩阵归一化得很好的更新，落到传播特征上仍可能被放大。
- 方法：GraphMuon 在由传播表示定义的 metric 里做正交化，并按更新对层表示的诱导效应归一化步长。理论部分证明 vanilla Muon 会遭受 graph-induced update amplification，GraphMuon 能缓解，得到 Muon polar update 的 graph-metric 类比。
- 数字：3 个大规模 OGB benchmark 上，validation-loss time-to-target 比 AdamW 快 1.32–2.42 倍；在节点分类、inductive 图分类、图回归共 15 个 dataset-architecture 配置里，13 个 time-to-target 更低，预测性能保持竞争或更好。
- 为什么值得看：Muon 的「矩阵几何」假设在 GNN 上不成立，这篇给出了修正版。对所有把 Muon 往非 transformer 结构上搬的人，它提供了一个可复用的检查项：先看输入表示的协方差，再看权重矩阵。

### 11. Mixed Signals（1↑）

Weight-Space Programming for EEG and ECG · EPFL · [2611.13758](https://huggingface.co/papers/2611.13758) · [项目页](https://daravaram.github.io/BioWSP)

- 问题：weight-space programming 让语言模型读出一个已训练网络的权重并直接编辑，等于「靠推理训练」而不是梯度下降。此前在游戏网络、LLM 故障修复、扩散模型上都有演示，但没人在 EEG/ECG 这类生物信号小模型上试过。
- 实验：让前沿模型在不知道故障是什么的前提下 debug 植入的 fault；再进一步，只给架构、任务和少量训练受试者，让它从零写出网络的全部权重。
- 数字：一组实验里，语言模型仅靠推理、不跑任何梯度步，用少 6 倍的训练受试者就匹配了标准梯度下降训练；Claude Opus 5.5 写出的网络在同样 5 个受试者上，分数高于经典手工 EEG 管线（alpha band power、CSP + LDA）。
- 边界：模型无法改进已经训练好的分类模型；也无法仅从权重可靠识别网络是为什么任务训练的。作者的结论很克制：对小网络（边缘设备、可穿戴）有用，但离实用还早。
- 为什么值得看：它把 weight-space programming 的适用边界画了出来——小网络、坏模型、有明确架构先验时可行；好模型和任务识别不行。对「让 agent 改权重」的叙事，这是必要的负面证据。

## 补抓：首轮漏掉的 6 篇

首轮只拿到 11 篇（上游「按日期查」返回 0、日期页只给 11），补齐后 17 篇。6 篇票数都不高，但有两篇值得记：

- **[Evolving Infra](https://huggingface.co/papers/2611.12304)**（4↑，MIT HAN Lab）：把「算力分配」和「KV cache 管理」解耦的 agent-adaptive serving——节点可在 prefill / decode 之间高效切换，在线 planner 按负载组成决定 PD 切分，agent-aware KV 管理器用 agent 上下文管理的信号指导驱逐与迁移（避免淘汰 agent 马上要复用的缓存）。在 coding / math / computer-use 三类任务、GLM-5.2 与 Kimi K2.6、最多 256 张 GB300 上跑。
- **[Where Does Alignment Emerge](https://huggingface.co/papers/2611.12869)**（3↑，TUM）：给「柏拉图表示假说」补条件——跨模态对齐随层与维度的 emergence 位置不同；**只要 caption 足够干净信息量足够**，新模型的对齐趋势依然成立；并给出单模态/多模态基线，发现单模态模型的跨模态对齐可以超过显式对齐的 VLM，但仍远落后于同模态之间。
- **[Precision on Demand](https://huggingface.co/papers/2611.14418)**（1↑）：本地解码不必全程一个精度——存 8 bit、用高 4 bit 解码，只在低精度分布「看起来不确定」时（熵超阈值或 top-2 margin 小）用 8 bit 重算该步。Qwen3-0.6B + GSM8K，成本按每 token 读的权重字节算：36,724 个重放步上，低精度熵对 argmax 翻转的 AUC 0.93；15% 升级预算抓到 78% 翻转（margin 门 94%），但 150 道实测里熵门与两端都没有统计显著的分离（p=0.080）。
- **[CARTBench](https://huggingface.co/papers/2611.05862)**：购物助手的 rubric 评测——17 个零售域、带时间戳的多轮对话 + 1,603 条商品记录，1,328 条专家标注的 Core / Excellence / Safety 判据；10 个模型里 3 个在 Core 上超 90%。
- **[PolyRoute](https://huggingface.co/papers/2611.13843)**：12 语言、9 种书写系统、156 条 code-mixed 消息的类型化决策路由基准，13 个系统的榜：英文根模型 61.2%、多语模型 77.3%、最好微调 96.6%，TF-IDF + 逻辑回归就到 91.9%——一个提醒：这类任务上简单基线很强。
- **[Bits or permutations?](https://huggingface.co/papers/2611.14413)**（0↑）：固定推理预算，花在权重精度上还是花在选项顺序平均上？Qwen3-0.6B/1.7B 模拟量化：6 bit 不掉分，4 bit 时答案槽偏斜从 0.15 升到 0.53，但等功率高斯噪声的对照也不结论明确。

## 今天的三个观察

1. **教科书成了当天最集中的监督源，而且离线与在线两条路都跑通了**。 TOME-Math 把 2,118 本教材转成约 380K 条带章节顺序、命题依赖和 provenance 的记录，全量微调平均分 +16.7 分，压过三个公开 instruction baseline；Self-Learning RL 不给参考解，让 35B 模型自己读教材写证明，proof accuracy 51.5%→79.5%，还把 +1.7/+2.3 分带到 BrowseComp-Plus 与 CL-bench。两篇作者高度重叠，等于同一组人用两种口径回答了同一个问题：教材的价值在结构，不在题量。真正难复制的不是那 380K 条数据，而是保留依赖边之后的数据管线。

2. **Agent 的瓶颈从「能不能做」变成「在哪评、花多少**」。 GTAGym 用引擎状态自动判定 103 个 GTA V 任务，最佳模型 70.9%，但空中导航、逃逸、拦截仍做不好；IVG-Bench 把用户也模拟进去，最强 Gemini 4 Argon 限时只完成 53.4%，说明开放交互里的失败是结构性的，不是榜单噪声。同一天三条降本路线各切一层：PISA-E 在路由层省 36%/25% 成本还涨 2.09/2.87 分，SparseRead 在输入层把 token 砍掉最多 92.9%，SteerDistill 在权重层用 W4A16 把与 BF16 的差距压到 1 分内、训练 GPU 时间少 67%。三者可以叠加，因为它们改的不是同一个东西。

3. **评测的「协议效应」已经大到盖过模型差异**。 WMIP 同一批题，单步算术 84.9%，3–7 次更新后 31.7%，换一个「写出步骤、答案放最后一行」的协议就到 88.0%，而 50 次更新以上所有模型都不到 10%；CogBattery 的 54 个模型效应方向像人，false alarm、置信度校准、wager 行为都不像，更大模型也不稳定更接近人类；Mixed Signals 则从反面证明，权重里读不出网络在做什么任务。今天只有 11 篇、67 票，是近期最冷的一天——前一天还有 29 篇、325 票——但恰恰是这种小样本日，三篇评测/分析工作把「别信单点分数」讲得最清楚。

## 数据与方法

- 抓取：`python3 code/ai-daily/fetch_papers.py --date 2026-11-12`；首抓 2026-11-12 21:00（11 篇），21:05 重抓补齐（17 篇）。
- 数据源：官方 API 与 huggingface.co 页面在本机均不可达（connection reset）；mirror 的 `?date=` 返回 0，日期页只给 11 篇。「**最新一批」接口在不同 limit 下返回不同切片**（limit=100 是旧快照、没有当天；limit=30 才有），最终按 30/100/50 三个 limit 取并集 + 日期页，得到 17 篇。这条已写进 `code/ai-daily/README.md`。
- 规模：17 篇、127 upvotes，6 篇上双，中位数 2 票。Top 10 按 upvotes 取前十（第 10 名 0 票，与后面同票，按接口返回顺序取），分组为人工按主题归并，组内按 upvotes 降序。
- 数字口径：所有数字只取自接口返回的 abstract；摘要没给数值的地方不补、不外推。upvotes 会随时间变化，本文以抓取那一刻为准。
- 时间口径：`daily` 收录日 = 2026-11-12（`submittedOnDailyAt`），与 arXiv 首发日（2026-10-29 ~ 11-10）不同。
- 样本提醒：17 篇仍低于近期均值，且 daily 列表在当天晚上还会继续进人；本文只对抓到的 17 篇负责，不把「今天论文少」当成领域趋势。
