# indexer↔主注意力的真实头结构：低秩共享 q/k、逐头对齐 ρ_h 谱，与逐头权重的真正边界

> 本篇是「DeepSeek Mega MoE 前向 / 反向算子实现解析」专题的增量（P166-1）。
> 承接第 175 篇（`docs/175`）：那篇证明 indexer 一次选出的共享支持集 `S_t = Top-k(I_t,:)`
> 的蒸馏目标应**按下游重要度 `ν_h`（≈值范数²）加权、而不是按熵**，并给出 `ρ=0.5` 时熵加权
> 比均匀**差 7.1%** 的数。但它和第 173 篇（`docs/173`）有一个共同前提——**各头是 iid 的**：
> 用「`ρ` 旋钮 + 逐头独立噪声」参数化。`docs/175` §边界 3 自己也点明「真实 hidden 头间可能有
> 结构性相关（低秩共享 q/k）」未建模。
>
> 真实 DSA 的头**不独立**：GQA 让同组 query 头共享同一份 key/value，预训练又把各头推向前几个
> 主方向——**头间有低秩共同成分**。本篇把「参数化建模」换成**真实、低秩的 q/k**，回答两件事：
>
> **① 逐头对齐 `ρ_h` 本来就不均**（indexer 是另训小模型，对有的头贴得紧、对有的松），不是一个
> 全局 `ρ`；**② 头间相关会改变逐头权重的价值**——头越像，支持集对谁服务越无所谓，第 175 篇的
> 逐头权重杠杆会**收缩**。
>
> 结论是一个**边界修正**：在真实低秩头结构上（rank≥4，头间相关 ~0.63、有效头数 `H_eff≈2/32`），
> **第 175 篇「按 ν 加权」的方向仍对，但幅度从「+0.35%/熵罚 +0.18%」塌到 ±0.05% 以内**——头间

> **新发现**：逐头误差最好的预测器不是熵（+0.82），而是**该头与 indexer 的对齐度 `ρ_h`（−0.89）**。

## 0. 结论先行

在真实 SM90 `fp8_fp4_mqa_logits` 锚定（max-abs-rel **2.538e-04**，与第 173/175 篇逐位一致）的
DSA 头结构上（`T=256, C=16384, H_q=32, H_kv=8, G=4, D=128, dv=64, topk=2048`，indexer
`H=32, d=64`，逐头温度 `τ_h∈[10^{-1},10^{1}]`，逐 KV 组值尺度随机），H100(sm90) 实测：

1. **真实低秩 q/k 让头高度冗余**：共享子空间 rank=8、逐头偏移 `α_h∈[0.032,3.162]` 时，
   头间平均相关 **+0.641**、**有效头数 `H_eff = 1.97 / 32`**（相关系数矩阵特征值的参与率，§3.2）。
   32 个 query 头**实际只有约 2 个独立方向**。
2. **逐头对齐 `ρ_h` 是一个谱，不是单一 `ρ`**：`ρ_h ∈ [0.279, 0.836]`、std **0.188**、
   mean 0.685；且 `corr(α_h, ρ_h) = −0.980`——**一个头偏离共享子空间越远、与 indexer 越不贴**
   （§3.3）。第 173/175 篇的「全局 `ρ`」是一个过度简化。
3. **在真实低秩头结构上，逐头权重的杠杆塌了**：`ν` 加权相对均匀只赢 **+0.14%**（第 175 篇
   iid 工作点是 +0.35%），而**熵加权 ≈ 均匀（−0.02%）**——第 175 篇「熵比均匀差 0.18%」这条
   **在强头相关下不成立**（§3.4）。头越像，逐头权重越无所谓。
4. **头间相关是主轴**：共享 rank 从 1→32（头间相关 0.47→0.67、`H_eff` 3.13→1.86），
   `ν` 收益 **+2.54%→+0.28%**、熵罚 **+0.76%→+0.04%**、**头共享税 +32.4%→+4.99%**，全部单调
   收缩（§3.5）。第 175 篇量的 `ρ` 依赖是「头不一致度」的一个侧面，**头间相关是另一个（且更强）的轴**。
5. **逐头误差的真实预测器是对齐度 `ρ_h`，不是熵**：均匀支持下的逐头误差 `err_h` 与
   `corr(ent_h,err_h)=+0.817`、`corr(ν_h,err_h)=−0.257`，而与**新变量 `ρ_h` 相关 −0.892**
   （§3.6）。「哪头脏」的物理含义是「哪头 indexer 没对齐」，熵只是它的代理。
6. **`λ=ν^p` 在强头相关下几乎平**：`δ_value` 从 p=0 的 `4.9937e-2` 单调降到 p=3 的 `4.9853e-2`
   （总变化 **0.17%**），不存在第 175 篇 iid 情形里 p≈2 的清晰最优点（§3.7）。

## 1. 定位：从「iid 参数化头」到「真实低秩 q/k」

第 173/175 篇建立的头结构模型是：

```
a[t,h,j] = ρ·Î[t,j] + √(1−ρ²)·g_h·ε[t,h,j]          ε 逐头 iid  # docs/173 §2 / docs/175 §2
```

它把三个变量分开：`ρ`（indexer 对齐）、`g_h`（逐头尖锐度/温度）、`ε`（逐头独立噪声）。
但真实头之间的 `ε` **不独立**——预训练让各头共享主方向，GQA 又让同组头共享 key/value。
把它写清楚：

```
a[t,h,j] = ρ·Î[t,j] + √(1−ρ²)·( √κ·S[t,j] + √(1−κ)·ε[t,h,j] )     S 全头共享、κ 共享占比
```

`κ` 就是「头间相关」的新轴：`κ=0` 退回第 173/175 篇 iid；`κ→1` 所有头打分相同。本篇**不直接
拿 `κ` 调参**，而是用**真实 q/k** 造出实际的头间相关，再量它对下游与逐头权重的影响。

模型（`build_real_qk`）：各头 key/value 共享一个 rank 维子空间（预训练主方向），再叠逐头偏移：

```
U ∈ R^{rank×D} 正交
Kbase = B @ U,   B ∈ R^{C×rank}            # 共享分量（rank 维）
Kheads[g] = Kbase + α_g·offset_g           # 逐 KV 组偏移（GQA：同组 query 头共享 key）
Qheads[h] = Qbase + α_h·offset_h           # 逐 query 头偏移，α_h 取 logspace 谱
a[t,h,j] = <Qheads[h,t], Kheads[h//G,j]> / √D
```

`α_h` 取 `logspace(-1.5, 0.5, H_q)`：既有几乎落在共享子空间里的头、也有明显偏离的头。

## 2. 实验设置

- **indexer 打分**（Part A）：真实 SM90 `fp8_fp4_mqa_logits`，`q=(fp8, None)`、`kv=(fp8, 逐 token
  fp32 sf)`、`weights` fp32，对应 `attention.hpp:67-134`；与纯 torch 复刻对拍 max-abs-rel。
- **主注意力头结构**：真实低秩 q/k（§1），`V` 逐 KV 组随机值尺度（让下游重要度 `ν_h≈||V||²`
  与尖锐度**解耦**）。
- **indexer 是「另训小模型」**：从共享子空间读出的单头打分器 + 自身噪声
  （`I_raw = standardize(shared) + 0.6·standardize(noise)`）。
- **下游**：per-head softmax + GQA 共享支持集（第 173 篇同款）：
  `S_t=Top-k(I_t,:)` 逐 token 选一次、对全部 `H_q` 头共享；`O[t,h,:]=Σ_{s∈S_t} P_h_renorm[t,s]·V[s,g(h)]`。
- **逐头权重方案 `λ`**：支持集 = `Top-k(p_λ)`、`p_λ = Σ_h λ_h P_h / Σ_h λ_h`（第 175 篇的蒸馏
  不动点框架）；评判量 `δ_value = sqrt(Σ_h ν_h||O_S−O_full||² / Σ_h ν_h||O_full||²)`。

## 3. 结果

### 3.1 Part A：kernel 锚定

```
kernel vs torch-fp8 ref: max-abs-rel = 2.538e-04
```

与第 173/175 篇逐位一致（同一 seed/量化语义），坐实后续所有「结构变量」是在**真实打分算子**
的量化地板上做的。

### 3.2 Part B：真实低秩 q/k —— 头高度冗余

```
rank=8: 头间平均相关 = +0.641   H_eff = 1.97 / H_q=32
逐头偏移 alpha_h: min=0.032 max=3.162
```

`H_eff` = 头间相关系数矩阵特征值的参与率（`(Σλ)²/Σλ²`）。**rank=8 时 32 个头只有约 2 个有效
方向**（mean corr 0.64 ⇒ 谱为 `1+0.64·31≈20.8` 主导 + 31 个 `0.36`）。这意味着「头共享支持集」
的信息损失**天然比第 175 篇假设的小得多**——头之间本就没那么不同。

### 3.3 Part C：逐头对齐 `ρ_h` 谱

```
rho_h: min=+0.279 max=+0.836 std=0.188 mean=+0.685
最贴 4 头 rho = [0.836, 0.835, 0.835, 0.835]   最松 4 头 rho = [0.377, 0.324, 0.286, 0.279]
corr(alpha_h, rho_h) = -0.980
```

**这不是一个全局 `ρ`**：最贴的 4 头 `ρ≈0.84`，最松的 4 头 `ρ<0.38`。而 `corr(α_h,ρ_h)=−0.980`
给出机制解释——**indexer 学的是「共享主方向」（它是另训小模型，只能抓住跨头公共的部分），
所以越靠近共享子空间的头，indexer 对它贴得越紧**。第 173/175 篇那个「所有头同一个 `ρ`」
的旋钮，在真实结构里应替换为这个谱。

### 3.4 Part D：真实头结构上重跑逐头权重方案

```
λ=uniform      δ_equal=5.5783e-02  δ_value=4.9937e-02
λ=entropy(+)   δ_equal=5.5780e-02  δ_value=4.9927e-02
λ=inv-entropy  δ_equal=5.5815e-02  δ_value=4.9972e-02
λ=value-norm   δ_equal=5.5734e-02  δ_value=4.9866e-02
λ=sharp-only   δ_equal=5.6127e-02  δ_value=5.0274e-02
oracle（逐头各自 top-k）         δ_equal=5.2913e-02  δ_value=4.7390e-02
```

- **`ν` 加权仍最好**（`4.9866e-2`，比均匀 `4.9937e-2` 好 **+0.14%**）——第 175 篇的方向保住；
- **但熵加权 ≈ 均匀**（`4.9927e-2`，**−0.02%**，即熵反而微微更好）——第 175 篇「熵比均匀差
  0.18%」在此**不成立**；
- 只有极端方案（`sharp-only`，只服务最尖头）才明显更差（+0.67%），与第 175 篇一致。

**读法**：逐头权重是一个 **<0.2%** 的杠杆，头间相关越强越小；第 175 篇 iid 下的 0.18–0.35%
是它在该结构下的**上界**，不是普遍值。

### 3.5 Part E：头间相关是主轴

```
rank= 1: 头间相关=+0.466 H_eff= 3.13  ν收益=+2.541%  熵罚=+0.758%  头共享税=+32.38%
rank= 2: 头间相关=+0.566 H_eff= 2.35  ν收益=+0.908%  熵罚=-0.007%  头共享税=+11.89%
rank= 4: 头间相关=+0.624 H_eff= 2.05  ν收益=+0.195%  熵罚=+0.014%  头共享税=+7.27%
rank= 8: 头间相关=+0.641 H_eff= 1.97  ν收益=+0.143%  熵罚=-0.020%  头共享税=+5.38%
rank=16: 头间相关=+0.667 H_eff= 1.88  ν收益=+0.170%  熵罚=+0.025%  头共享税=+5.21%
rank=32: 头间相关=+0.671 H_eff= 1.86  ν收益=+0.280%  熵罚=+0.037%  头共享税=+4.99%
```

共享 rank 越大 ⇒ 共享分量越强 ⇒ 头间相关越高、`H_eff` 越低，随之：

- **`ν` 收益单调收缩**（rank=1 的 +2.54% → rank≥4 的 ~0.2%）：头越像，给谁加权越无所谓；
- **熵罚消失**（+0.76% → 0），第 175 篇的「熵是错的权重」只在头**较不一致**时可见；
- **头共享税单调收缩**（+32.4% → +5.0%）：头越相关，用共享支持集近似逐头 oracle 越不亏。

第 175 篇把这几件事归给「`ρ`（indexer 对齐）」；本篇说明**头间相关 `κ` 是独立的、且更强的轴**：
即便 `ρ` 固定，光靠头间结构就能把逐头权重杠杆和头共享税都压下去。

### 3.6 Part F：逐头误差的真实预测器是对齐度 `ρ_h`

```
corr(ent_h, 均匀支持下的逐头误差 err_h) = +0.817
corr(ν_h,  均匀支持下的逐头误差 err_h) = -0.257
corr(rho_h, 均匀支持下的逐头误差 err_h) = -0.892
```

**复现第 173/175 篇**（熵-误差 +0.82），但加入真实结构后**新的最强预测器是 `ρ_h`（−0.892）**：
均匀支持集下误差最大的头，正是**与 indexer 最不贴**的头。熵能预测误差（+0.82）只是因为
「平头」同时倾向于「偏得远」——**熵是 `ρ_h` 的代理，`ρ_h` 才是因**。这也解释了为什么第 173
篇「把蒸馏权重落在平头」的直觉是错的：该落的地方是**indexer 抓不住的（低 `ρ_h`）头**，
而低 `ρ_h` 与「平」在真实结构里同源、但机制不同。

### 3.7 Part G：`λ=ν^p` 扫描

```
p=0.0: δ_value=4.9937e-02   p=1.0: 4.9866e-02   p=2.0: 4.9865e-02   p=3.0: 4.9853e-02
```

在强头相关下 `δ_value` 随 p **单调缓降**（总变化 **0.17%**）、**无第 175 篇那样清晰的 p≈2
最优**——因为差异本身已被头冗余压平，`p` 的选择不重要。再次说明：**先看头结构，再谈 `p`。**

## 4. 三条「为什么」

1. **为什么头会高度冗余（`H_eff≈2/32`）**：预训练把各头推向前几个主方向（共享子空间），
   GQA 又让同组头共享 key/value。所以「32 头」的**信息维度远小于 32**——这直接决定 head-sharing
   的税很小（§3.5 rank≥8 只有 ~5%），也决定逐头权重杠杆很小。
2. **为什么 `ρ_h` 谱由「离共享子空间的距离」决定**：indexer 是**单头打分器**、且是**另训**的，
   它只能抓住跨头公共（共享子空间）的部分；一个头越偏离这个子空间（`α_h` 越大），indexer 对
   它的预测越差 ⇒ `corr(α_h,ρ_h)=−0.98`（§3.3）。于是逐头误差也随 `α_h` 增大（§3.6 `ρ_h` 相关 −0.89）。
3. **为什么头间相关会「吃掉」逐头权重**：支持集是 `Top-k(p_λ)`；头越共线，各 `P_h` 的排序越
   接近，任何 `λ` 混合出的 `p_λ` 排序都几乎一样 ⇒ `δ` 对 `λ` 不敏感（§3.4）。头越不一致，
   混合权重才真正改变 `Top-k`（§3.5 rank=1 的 +2.54%）。**逐头权重是「头不一致时的补偿」**。

  真实低秩头结构下 `ν` 收益从 +0.35% 塌到 +0.14%、熵罚从 +0.18% 塌到 ~0，且引入**头间相关**
  这一独立且更强的轴（§3.5）。
- 第 173 篇（`docs/173`）用「全局 `ρ` + 逐头 iid 噪声」；本篇把 `ρ` 换成**真实 q/k 里的 `ρ_h` 谱**

- 第 174 篇（`docs/174`）发现 indexer 自身 `w_h` 已编码逐头重要性、逐头分精度无用；本篇从主注意力

- 第 171/172 篇（`docs/171`、`docs/172`）证明选择翻转是二阶；本篇的「头共享税 ≤5%」复核了

## 6. 结论与边界

- **结论**：真实 DSA 主注意力的头**高度冗余**（`H_eff≈2/32`）、**逐头对齐 `ρ_h` 是一个由
  「离共享子空间距离」决定的谱**（`corr(α_h,ρ_h)=−0.98`）。在这之上：
  **第 175 篇「按 `ν` 不按熵」方向对、但幅度是 iid 结构下的上界**——真实结构里 `ν` 只赢
  ~0.14%、熵 ≈ 均匀；**头间相关是独立且更强的主轴**，它把逐头权重杠杆与头共享税一起压下去
  （rank 1→32：+2.54%→+0.28%、+32%→+5%）。**逐头误差的最好预测器是 `ρ_h`（−0.89）而非熵（+0.82）**。
  实务准则：**先把 indexer 的「抓得住共享方向」能力做够（抬 `ρ_h`），逐头权重与 `p` 都是零头。**
- **边界 1**：头结构是**参数化的真实低秩 q/k**（共享子空间 + 逐头偏移），不是真训练出的 DSA；
  `α_h` 谱形状、`rank` 与相关强度是可控工作点。「`H_eff≈2`」这个具体数依赖该构造，但
  「头冗余 + `ρ_h` 谱 + 轴单调」是结构性的。
- **边界 2**：本机 H100（sm90）只能跑 **fp8 档**真实 kernel（`attention.hpp:124-130`）；
  MXFP8/MXFP4 是 SM100 专属、用纯 torch 复刻（`math.py` 语义）分析，**仅分析**；主 kernel 的
  UMMA/UTCCP 部分未在本机执行。
- **边界 3**：下游重要度 `ν_h` 用**随机 `V` 的范数²**代理；真实 loss 对头的权重另有来源。
  本实验只证明「头间相关会压缩逐头权重价值」，不主张某个具体 `ν` 的定义。
