    断言 `sizeof(epilogue_operator_t) == sizeof(EpilogueOperatorArgs)`：

    FP8 字节不符 0 / 16777216（dgate+dup 两输出），SF 不符 0 / 524288

[C] 单输出共享 SF 的代价：dgate/dup 每 32 元素独立 SF；若强行共用一个 SF，
    dup 的等效比例偏差 RMS = 0.8506（SF 比值 2^(e_dgate-e_dup) 偏离 1 的均方根）。
    两输出 SF 分布不同 ⇒ 契约必须给**两个** SFD。

[C2] 只走「单输出」分支（two_output=0）：dup 非零元素 0 / 8388608
     第二输出**根本不会被写**——不是精度问题，是契约留不出第二个张量。

======================================================================

======================================================================
  epilogue_class.hpp 返回的 operator 类型字符串（4 个）：
    epilogue::operators::Identity              -> operators.cuh struct Identity                 [OK]
    epilogue::operators::ScaleByAlpha          -> operators.cuh struct ScaleByAlpha             [OK]

  => host 类型字符串与 device operator 1:1；新增 operator 的**唯一**接线点就是这里多返回一个字符串。

======================================================================
③ resolve_epilogue_class 的互斥（epilogue_class.hpp:111-127 的 Python 复刻）
======================================================================
    默认（三者都无）                         -> IdentityEpilogue (默认)
    alpha=0.5                        -> AlphaEpilogue (check: d bf16/fp32)
    sfd（FP8 输出对）                     -> FP8QuantizationEpilogue (单输出 D + 单 SFD)
    sfd + c（非法）                      -> ASSERT: FP8 量化要求 not c 且 d==E4M3
    sfd + d=fp32（非法）                 -> ASSERT: FP8 量化要求 not c 且 d==E4M3
    epilogue_class + alpha（非法）       -> ASSERT: epilogue_class / alpha / sfd 三者互斥
    epilogue_class + sfd（非法）         -> ASSERT: epilogue_class / alpha / sfd 三者互斥

======================================================================
④ 单输出契约放不下 SwiGLU 反向（要 2 张量 + 2 SFD）
======================================================================
  当前 EpilogueClass 只表达：1 个 D（tensor_map_cd）+ 可选 1 个 SFD（`output_sfd()` :38）。
  FP8 输出对还要求 `not c`（epilogue_class.hpp:84）——连 C 都被占掉。
  SwiGLU 反向需要：d(gate) 张量 + d(up) 张量 + 各自 SFD = 2 数据 + 2 SF。
  => 必须扩 3 处契约：(a) EpilogueOperatorArgs 加逐元素输入/第二输出指针；
     (b) resolve/check 支持双输出；(c) sm100_store_cd.cuh 的 is_same_v 分支加一条双写。
  SM90 分支直接拒绝自定义 epilogue：gemm.hpp:238 “Custom epilogues require SM100”。
